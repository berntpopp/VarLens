# Milestone v0.4.0: Variant Annotation & Case Metadata

**Status:** ✅ SHIPPED 2026-01-29
**Phases:** 19-25
**Total Plans:** 27 (including gap closures)

## Overview

Transforms Varlens from a read-only viewer into an active analysis workbench with variant annotation, classification, enriched detail views, and structured case metadata.

## Phases

### Phase 19: Database Foundation

**Goal**: Database schema supports all annotation, case metadata, and API caching features with encrypted DB migration validated.

**Depends on**: Nothing (extends v0.3.0 schema)

**Requirements**: INFRA-01, INFRA-02, INFRA-06

**Plans**: 2 plans

- [x] 19-01-PLAN.md — Schema additions, migration system with PRAGMA user_version, TypeScript types
- [x] 19-02-PLAN.md — Migration tests on encrypted databases, cascade delete verification

**Details:**
Schema migration uses PRAGMA user_version for version tracking. Added tables: variant_annotations, case_variant_annotations, case_metadata, cohort_groups, case_cohort_links, api_cache, tags, variant_tags. Foreign keys with CASCADE DELETE for data integrity. Temp file testing pattern for SQLCipher encrypted database tests.

### Phase 20: Annotation Core

**Goal**: Users can annotate variants with comments, stars/flags, and ACMG classification with persistent storage.

**Depends on**: Phase 19 (schema must exist)

**Requirements**: ANNOT-01, ANNOT-02, ANNOT-03, ANNOT-04, ANNOT-05, ANNOT-06, ANNOT-07, ANNOT-12, ANNOT-13

**Plans**: 4 plans

- [x] 20-01-PLAN.md — Backend: IPC handlers + DatabaseService annotation methods
- [x] 20-02-PLAN.md — Frontend: VariantTable star + ACMG columns, useAnnotations composable
- [x] 20-03-PLAN.md — Gap closure: Extend useAnnotations with comment and ACMG mutation methods
- [x] 20-04-PLAN.md — Gap closure: AcmgMenu and CommentDialog UI components

**Details:**
Atomic annotation upsert with INSERT ON CONFLICT DO UPDATE. Per-case stars and ACMG classification (schema migration v3). Global annotations visible in case mode with ring indicator. Optimistic UI updates with rollback on failure. Cohort mode supports global annotations.

### Phase 21: API Service Layer

**Goal**: VEP and HPO API clients provide enriched annotation data with SQLite caching, rate limiting, and graceful offline degradation.

**Depends on**: Phase 19 (api_cache table must exist)

**Requirements**: PANEL-03, PANEL-04, PANEL-07, PANEL-08, PANEL-09, PANEL-10, META-06, META-07, META-10, INFRA-03, INFRA-04

**Plans**: 3 plans

- [x] 21-01-PLAN.md — API infrastructure: ApiCache, NetworkStatus, zod schemas, clinical thresholds
- [x] 21-02-PLAN.md — VEP API client with rate limiting, caching, MANE Select transcript
- [x] 21-03-PLAN.md — HPO API client, VEP/HPO IPC handlers, preload API

**Details:**
Zod for API response validation. TTL jitter (±10%) prevents thundering herd. Bottleneck rate limiter (15 req/sec). Exponential backoff on 429 (1s, 2s, 4s). Request cancellation with AbortController. MANE Select transcript prioritization. Courtesy rate limiting for HPO (5 req/sec). NetworkStatus singleton for offline detection.

## Milestone Summary

**Decimal Phases:**
None — all phases were integer phases in this milestone.

**Key Decisions:**
- PRAGMA user_version migrations (version-tracked schema upgrades)
- Separate global/per-case annotations (variant_annotations has no FK to variants)
- Atomic annotation upsert (INSERT ON CONFLICT DO UPDATE with COALESCE)
- Per-case starred and ACMG (schema migration v3)
- Zod for API validation (TypeScript-first schema library)
- Bottleneck rate limiting (15 req/sec for Ensembl VEP)
- MANE Select prioritization (clinical best practice)
- Bundled HPO JSON (offline search with 19k terms)
- varlens_ localStorage prefix (consistent naming)

**Issues Resolved:**
- VEP rate limiting prevents API overload
- Offline-first API degradation works gracefully
- Tag filtering now works via subquery pattern
- Column and filter preferences persist across sessions
- Case metadata accessible via modal without clutter

**Issues Deferred:**
- Franklin URL format has LOW confidence
- VEP API platform transition in 2026 may break response parsing
- Cohort performance not profiled with 50+ cases

**Technical Debt Incurred:**
- Debug console.log in DatabaseService (info-level)
