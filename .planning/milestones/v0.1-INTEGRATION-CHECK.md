## 4. Data Flow Architecture

### 4.1 Import Data Pipeline

```
User File Selection
  ↓
Electron File Dialog (import:selectFile)
  ↓
ImportDialog UI (caseName input)
  ↓
import:start IPC
  ↓
ImportService.importVariants()
  ├── extractCaseId() → case ID from JSON header
  ├── extractDictionaries() → Gene dictionary for ID→symbol mapping
  ├── createCase() → DatabaseService creates case record
  └── Pipeline:
      createReadStream(filePath)
        → createGunzip()
        → parser() [stream-json]
        → pick(caseId.data) [extract data array]
        → streamArray() [emit array elements]
        → FieldMapper [map raw → Variant type]
        → BatchAccumulator [accumulate 5000 rows]
          → DatabaseService.insertVariantsBatch()
            → SQLite transaction + FTS5 trigger
  ↓
import:progress events (throttled 100ms)
  ↓
ImportDialog progress bar
  ↓
import-complete event
  ↓
App.vue orchestration:
  - CaseList.refreshCases()
  - CaseList.selectCase(caseId)
  - AppSnackbar.show(message)
```

✅ **Verified:** All stages connected. Memory-efficient streaming. Progress feedback works.

### 4.2 Variant Query Data Flow

```
User Action (filter change, sort, paginate)
  ↓
FilterToolbar or VariantTable state update
  ↓
Event emission (update:filters, v-model:page, v-model:sort-by)
  ↓
App.vue state (currentFilters, selectedCaseId)
  ↓
VariantTable props update
  ↓
Watch triggers loadVariants()
  ├── Build cursor cache key from sort + page
  ├── Get cursor from cache (undefined for page 1)
  ├── Serialize filters + sortBy (plain objects for IPC)
  └── window.api.variants.query(caseId, filters, cursor, limit, sortBy)
      ↓
      preload/index.ts → IPC invoke
        ↓
        ipc/handlers/variants.ts
          ↓
          getDatabaseService()
            ↓
            DatabaseService.getVariants(filter, limit, cursor, sortBy)
              ├── Build WHERE clause from filters
              ├── Build ORDER BY from sortBy (with NULL handling)
              ├── Build cursor condition (keyset pagination)
              └── Execute SQL with prepared statement
                ↓
                SQLite query returns rows + count
      ↓
      PaginatedResult<Variant> { data, next_cursor, has_more, total_count }
  ↓
VariantTable state update:
  - variants.value = result.data
  - totalCount.value = result.total_count
  - cursorCache.set(nextPage, result.next_cursor)
  ↓
Emit update:counts to App → FilterToolbar
  ↓
Table re-renders, count badge updates
```

✅ **Verified:** Filter → query → display loop intact. Cursor caching prevents redundant queries.

## 6. Integration Risks & Recommendations

### 6.1 Critical Integration Points

| Point | Status | Risk Level |
|-------|--------|------------|
| Import → Database | ✅ SOLID | LOW - Streaming pipeline with error handling |
| IPC → Preload → Renderer | ✅ SOLID | LOW - Type-safe bridge, contextIsolation enforced |
| Filter → Pagination | ✅ SOLID | LOW - Cursor invalidation on filter change |
| Case Selection → Variant Load | ✅ SOLID | LOW - Watch-based reactivity, filter clearing |
| Progress Events | ✅ SOLID | LOW - Throttled 100ms, cleanup on unmount |

### 6.2 Known Limitations (by Design)

1. **Single-instance imports:** Only one import can run at a time (AbortController singleton)
   - **Impact:** User can't import multiple files simultaneously
   - **Mitigation:** Import dialog blocks during import, cancel button available

2. **System APIs unused:** `system:version` and `system:userDataPath` not wired to UI
   - **Impact:** None on POC functionality
   - **Recommendation:** Add About dialog in future milestone

3. **Export not tested E2E:** Export handler exists, UI wired, but not in POC test flows
   - **Impact:** Functionality may have edge cases
   - **Recommendation:** Add to post-POC testing

### 6.3 Potential Improvements (Post-POC)

1. **Error boundary in App.vue:** No global error handler for IPC failures
   - **Current:** Errors logged to console, user sees no feedback
   - **Recommendation:** Add error snackbar in App.vue for IPC failures

2. **Loading states:** Some components lack loading indicators during IPC calls
   - **Current:** FilterToolbar gene search shows loading, but filter options load silently
   - **Recommendation:** Add loading state to FilterToolbar on mount

3. **Type casting in VariantTable:** Line 219 uses `(window as any).api`
   - **Current:** Works but bypasses TypeScript checking
   - **Recommendation:** Add proper `Window` interface extension in `env.d.ts`
