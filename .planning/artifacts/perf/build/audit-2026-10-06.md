Status: baseline and disposable probes; no implementation speedup is claimed.

Source: VarLens `8a662b89f75983d513f6c4b6cf52ac57b271946c`. An isolated worktree
and an independent copy of installed dependencies avoided changing the active

## Installer contents

After building desktop and web in the same worktree, the Linux package's asar
inventory (including unpacked entries) contains 332,107,728 bytes across 517
top-level groups. Its `out` subtree includes:

| Subtree  |          Bytes |
| -------- | -------------: |
| main     |      1,327,190 |
| preload  |         42,249 |
| renderer |     15,435,401 |
| **web**  | **46,937,662** |

The web subtree is caused by `build.files: ["out/**/*", ...]`. Hosted desktop
jobs on fresh runners do not normally have it. Local packaging after web work
therefore differs from a fresh desktop package. Restrict desktop inputs to
the three desktop output directories.

Largest additional dependency groups: `molstar` 67,675,041 B; `vuetify`
42,483,084 B; `pdbe-molstar` 12,959,544 B; native SQLite 34,443,173 B;
`sodium-native` 18,130,257 B; `swagger-ui-dist` 11,650,340 B.
Renderer-only dependencies are bundled by Vite and are candidates for
`devDependencies`, after verifying all main/preload/web runtime imports.
These are inventory bytes, not promised installer-size savings.

## Cache correctness probes

Prettier created `node_modules/.cache/prettier/.prettier-cache` and did not
create `.prettiercache`. Build restores/saves the latter. This confirms the
cache-path mismatch independently of its 14–20 s hosted formatting steps.

Using installed ESLint and the repository's strict boolean rule in a temporary
two-module project: an exported boolean type became `boolean | undefined`.
The unchanged importer was rejected by uncached lint (exit 1), while the warm
content cache returned exit 0. This is a demonstrated stale-cache failure.
The same gate must use fresh typed lint, or a complete source-graph fingerprint.

All three source tsconfigs enable `assumeChangesOnlyAffectDirectDependencies`
while CI restores incremental state. TypeScript documents incomplete diagnostics
with this option. Two small transitive-error probes nevertheless caught the
error under this installed TypeScript version; **this audit did not reproduce
a missed type diagnostic**. Remove the shortcut from authoritative gates as
a correctness policy, retaining supported incremental caching, rather than
claiming those probes demonstrated a failure.
