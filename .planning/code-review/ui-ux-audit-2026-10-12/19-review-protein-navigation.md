# 19 — Review: feat/protein-views-navigation (11 commits on feat/protein-view-discoverability, +3892/−2497, read-only)

**What this change does:** It replaces `useLollipopPlot` and `useGeneStructurePlot` (1579 lines) with one track model (`utils/track-*.ts`), one navigator (`useTrackNavigator`) and one renderer (`track-plot/*`, `components/protein/track/*`). Both views now have search, an overview strip, a List view, and a ±window neighbourhood panel with re-anchor and back. Most of it holds up: the pure functions have table tests, the anchor is never binned (`binMarkers` keeps it apart), the neighbourhood counts use the same filtered markers the plot draws, the redraw runs once per animation frame (rAF) and is cancelled on unmount, ClinVar class and consequence filters and the gnomAD AF/consequence filters and toggle are kept, every file is under 600 lines, and the two baseline removals are fine.

**Must fix**
1. **Exported SVG/PNG lose their colours and lines** (`track-plot/track-draw.ts:13-16,176`, `gene-view.ts:34`, `utils/svg-export.ts`). The plot now uses `rgb(var(--v-theme-…))` for the axis, intron line, backbone, stems and exons. An exported file, or the `<img>` drawn into the PNG canvas, has no Vuetify CSS variables. So fills turn black and strokes vanish. The old code used hex values. Fix: in `svgMarkup`, replace each `var(--v-theme-x)` with `getComputedStyle(svg).getPropertyValue('--v-theme-x')` before serialising. *Not confirmed by an export in the app.*
2. **A ClinVar diamond or bin takes the colour of whichever variant came first** (`track-draw.ts:121` `group[0].color`, `track-window.ts` bin `color: m.color`). Zoomed out, a Pathogenic diamond can be drawn green as Benign. The old `groupClinVarByPosition` used the dominant class. Fix: for `clinvar` groups and bins, use the worst class in `CLASS_ORDER`.

**Should fix**
3. **CNV/SV anchor context is wrong** (`track-markers.ts` `geneTrackData`, `track-neighbourhood.ts`). The anchor sits at the interval start. Take a whole-gene deletion that starts upstream: the anchor is outside the extent, so the band is not bound or focusable (`gene-view.ts` finds no `isAnchor`). The panel then says "In an intron · N bp to Exon 1" (`PLOT_COPY.outside` is never used), and ClinVar variants inside the deletion are not counted. Fix: for an interval, use the window `[pos−half, end+half]` and the `outside` label.
4. **Re-anchoring in a CNV gene view relabels the band** (`gene-view.ts`, the `isInterval(a)` branch). The band text and binding follow `ctx.markers.find(isAnchor)`, so the band shows the new ClinVar label and the new anchor gets no star. Fix: bind the band to `nav.originalAnchor`, and draw `anchorMarker` for the override.
5. **Pasted HGVS finds nothing** (`config/proteinPlotConfig.ts` `aaChange` is anchored with `$`). "p.Arg42GlyfsTer5", "p.Lys5del" and "ENSP…:p.Met180Val" all fall to a name search and show "No match", even though `normaliseAaChange` handles all three on the marker side. Fix: cut the input at its last `p.` before parsing, and fall back to `{kind:'position'}` when only ref+position parse. Add 3 table rows.
6. **Every marker is a Tab stop, and arrow steps are spoken twice** (`useTrackPlot.ts` `bindMarker` `tabindex 0`; `TrackPlot.vue:15` `liveText`). Leaving the plot takes up to 250+ Tab presses. Each ←/→ reads the focused button's label, and then the live region reads the same label again. Fix: use a roving tabindex (0 on the focused or anchor marker, −1 on the rest), and fill `liveText` only for search or list jumps, where focus does not move.
7. **The tooltip lost detail the old one had** (`TrackTooltip.vue` against the deleted `ProteinTooltip.vue`): CADD, the case variant's gnomAD AF, the ClinVar variation ID, gnomAD AC/AN, domain type and accession, and the list of co-located variants (now only "label +N"). Enter is also ignored on a same-position group (`binnedKeys` set), so those variants can be re-anchored only from the List. Fix: carry these fields on `TrackMarker`, add the rows, and list up to 5 group members.

**Nice to have**
8. **Right-edge bin falls off the plot** (`track-window.ts` `index`). When `plotWidth % BIN_PX === 0`, a marker exactly at `w.end` (for example a stop-loss at the last residue, crowded gene, full view) lands in bin n and is clipped. Fix: `Math.min(index, Math.ceil(plotWidthPx / binPx) - 1)`.
9. **Search status is not announced** (`TrackSearch.vue:50-57`). "No match" sits in no live region, and the "n of m" region is mounted together with its text, so screen readers often skip it. Fix: one always-mounted polite status span.
10. **Baseline churn** (`scripts/agent-health-baseline.json`). The file was re-serialised, so "—" became `—` in two unrelated reasons. Revert those two hunks.
