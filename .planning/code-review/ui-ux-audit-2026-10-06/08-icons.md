# Icon rendering findings (2026-10-06)

Probe: headless Chromium, 1440x900 @2x DPR, logged in, home + case LB26-0060 (scripts in session scratchpad).
All 470 `.v-icon` elements on the case view render valid `@mdi/js` SVG paths — no blank/missing glyphs from the SVG set itself. The visible problems are sizing, clipping and semantics.
