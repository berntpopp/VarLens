  <name>Task 3: Add FilterToolbar to CohortView for consistent filter UX</name>
  <files>src/renderer/src/components/CohortView.vue</files>
  <action>
The CohortView currently has a simple search bar above CohortTable. To provide consistent UX with Case Analysis, we need to add the same FilterToolbar pattern.

However, reviewing the CohortTable code, it only supports a simple search_term parameter, not the full filter set that VariantTable supports. The backend cohort.getVariants IPC only accepts search_term, sort_by, sort_order, limit, offset.

For Phase 25, we should provide visual consistency while acknowledging the backend limitations. Two approaches:

**Approach A (Recommended - Minimal Change):**
Keep the existing search bar in CohortTable but style it to match FilterToolbar's visual design. Add a note that advanced filters are not available in cohort view.

**Approach B (More Work):**
Create a simplified CohortFilterToolbar that only shows search, with the same styling as FilterToolbar but without the other filter groups.

Let's implement Approach A with visual consistency:

1. In CohortView.vue, the CohortTable is already rendered directly. The search bar is inside CohortTable.

2. For consistency, move the search bar styling to match FilterToolbar's search section:
   - Wrap the search field in a div with class "filter-section search-section"
   - Add the section label "Search" above it
   - Apply the same border-radius, background, and input styling

3. In CohortTable.vue, update the search bar template:
   ```vue
   <!-- Search bar with FilterToolbar-like styling -->
   <div class="filter-toolbar-container">
     <v-toolbar density="default" flat class="filter-toolbar px-3 py-3">
       <div class="filter-section search-section">
         <div class="section-label">
           <v-icon size="small" class="mr-1">mdi-magnify</v-icon>
           <span>Search</span>
         </div>
         <v-text-field
           v-model="searchTerm"
           prepend-inner-icon="mdi-magnify"
           placeholder="Gene, position (chr:pos), or HGVS..."
           clearable
           density="compact"
           variant="outlined"
           hide-details
           class="filter-input"
           :class="{ 'filter-active': searchTerm !== '' }"
           @update:model-value="handleSearchChange"
         />
       </div>

       <v-spacer />

       <!-- Results count -->
       <div class="results-section d-flex align-center ga-2">
         <v-chip
           :color="searchTerm !== '' ? 'primary' : 'default'"
           :variant="searchTerm !== '' ? 'flat' : 'tonal'"
           size="small"
           class="results-chip"
         >
           <v-icon start size="small">mdi-filter-variant</v-icon>
           <strong>{{ totalCount?.toLocaleString() ?? '0' }}</strong>
           <span class="mx-1 text-medium-emphasis">variants</span>
         </v-chip>

         <v-btn
           v-if="searchTerm !== ''"
           color="error"
           variant="tonal"
           size="small"
           prepend-icon="mdi-filter-off"
           @click="searchTerm = ''; handleSearchChange('')"
         >
           Clear

       </div>
     </v-toolbar>
   ```
