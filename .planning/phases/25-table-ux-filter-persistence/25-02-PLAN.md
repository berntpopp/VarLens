<task type="auto">
  <name>Task 1: Create ColumnVisibilityMenu component with drag-to-reorder</name>
  <files>src/renderer/src/components/ColumnVisibilityMenu.vue</files>
  <action>
Create a menu component for toggling column visibility AND reordering columns via drag-and-drop in the menu list.

Props:
- `columns: Array<{ key: string; title: string }>` - all available columns in current order
- `visibleColumns: string[]` - currently visible column keys
- `tableId: string` - passed to useColumnPreferences

Events:
- `@toggle:column` - emits column key when visibility toggled
- `@reorder` - emits new column order array when drag ends
- `@reset` - emits when reset clicked

Template structure using vuedraggable for reorderable list:
```vue
<template>
  <v-menu :close-on-content-click="false" max-width="350">
    <template #activator="{ props }">
      <v-btn v-bind="props" icon="mdi-table-column" size="small" variant="text">
        <v-tooltip activator="parent" location="bottom">Columns</v-tooltip>
      </v-btn>
    </template>
    <v-card>
      <v-card-title class="text-subtitle-2 py-2">
        Column Settings
      </v-card-title>
      <v-divider />
      <v-card-text class="pa-0">
        <v-list density="compact" max-height="400" class="overflow-y-auto">
          <v-list-subheader class="text-caption">
            Drag to reorder, click checkbox to show/hide
          </v-list-subheader>
          <draggable
            :model-value="columns"
            item-key="key"
            handle=".drag-handle"
            :animation="200"
            @update:model-value="handleReorder"
          >
            <template #item="{ element: column }">
              <v-list-item class="px-2">
                <template #prepend>
                  <v-icon class="drag-handle mr-2" size="small">mdi-drag-vertical</v-icon>
                  <v-checkbox-btn
                    :model-value="visibleColumns.includes(column.key)"
                    hide-details
                    @click.stop="emit('toggle:column', column.key)"
                  />
                </template>
                <v-list-item-title class="text-body-2">{{ column.title }}</v-list-item-title>
              </v-list-item>
            </template>
          </draggable>
        </v-list>
      </v-card-text>
      <v-divider />
      <v-card-actions class="pa-2">
        <v-btn
          variant="text"
          size="small"
          prepend-icon="mdi-refresh"
          @click="emit('reset')"
        >
          Reset to Defaults
        </v-btn>
      </v-card-actions>
    </v-card>
  </v-menu>
</template>

<script setup lang="ts">
import { defineProps, defineEmits } from 'vue'
import draggable from 'vuedraggable'

interface Column {
  key: string
  title: string
}

defineProps<{
  columns: Column[]
  visibleColumns: string[]
  tableId: string
}>()

const emit = defineEmits<{
  'toggle:column': [key: string]
  'reorder': [keys: string[]]
  'reset': []
}>()

const handleReorder = (newOrder: Column[]) => {
  emit('reorder', newOrder.map(c => c.key))
}
</script>

<style scoped>
.drag-handle {
  cursor: grab;
  opacity: 0.5;
}

.drag-handle:hover {
  opacity: 1;
}
</style>
```

Key design decisions:
- Use `:close-on-content-click="false"` so menu stays open during interactions
- Drag handle on left, checkbox next to it, then column name
- vuedraggable wraps v-list-item elements for smooth drag experience
- Subheader explains the interaction model
  </action>

<task type="auto">
  <name>Task 2: Integrate column preferences into VariantTable</name>
  <files>src/renderer/src/components/VariantTable.vue</files>
  <action>
Enhance VariantTable to use useColumnPreferences for column visibility and order.

1. Import useColumnPreferences and ColumnVisibilityMenu:
   ```typescript
   import { useColumnPreferences } from '../composables/useColumnPreferences'
   import ColumnVisibilityMenu from './ColumnVisibilityMenu.vue'
   ```

2. Initialize preferences:
   ```typescript
   const { prefs, resetToDefaults, toggleColumnVisibility, setColumnOrder } = useColumnPreferences('variant-table')
   ```

3. Create computed `orderedColumns` that represents all columns in user's preferred order:
   ```typescript
   const orderedColumns = computed(() => {
     const base = headers.value
     if (prefs.value.order.length > 0) {
       // Sort by saved order, items not in order go to end
       return [...base].sort((a, b) => {
         const aIdx = prefs.value.order.indexOf(a.key)
         const bIdx = prefs.value.order.indexOf(b.key)
         if (aIdx === -1 && bIdx === -1) return 0
         if (aIdx === -1) return 1
         if (bIdx === -1) return -1
         return aIdx - bIdx
       })
     }
     return base
   })
   ```

4. Create computed `visibleHeaders` that filters by visibility:
   ```typescript
   const visibleHeaders = computed(() => {
     return orderedColumns.value.filter(h => prefs.value.visibility[h.key] !== false)
   })
   ```

5. Use `visibleHeaders` instead of `headers` in v-data-table-server `:headers` prop.

6. Add ColumnVisibilityMenu in a toolbar row above the table:
   ```vue
   <div class="d-flex justify-end pa-2">
     <ColumnVisibilityMenu
       :columns="orderedColumns.map(h => ({ key: h.key, title: h.title }))"
       :visible-columns="visibleHeaders.map(h => h.key)"
       table-id="variant-table"
       @toggle:column="toggleColumnVisibility"
       @reorder="setColumnOrder"
       @reset="resetToDefaults"
     />
   </div>
   ```

7. Add CSS for column max-width with ellipsis. In the existing style section, add:
   ```css
   :deep(.v-data-table th),
   :deep(.v-data-table td) {
     max-width: 200px;
     overflow: hidden;
     text-overflow: ellipsis;
     white-space: nowrap;
   }

   /* Ensure table can scroll horizontally when columns overflow */
   :deep(.v-table__wrapper) {
     overflow-x: auto;
   }
   ```

Note: The table already has tooltip handling for long allele values. This CSS applies globally to all cells as a fallback.
