  <action>
Create a menu component for toggling column visibility.

Props:
- `columns: Array<{ key: string; title: string }>` - all available columns
- `visibleColumns: string[]` - currently visible column keys
- `tableId: string` - passed to useColumnPreferences

Events:
- `@toggle:column` - emits column key when toggled
- `@reset` - emits when reset clicked

Template structure:
```vue
<v-menu>
  <template #activator="{ props }">
    <v-btn v-bind="props" icon="mdi-table-column" size="small" variant="text">
      <v-tooltip activator="parent" location="bottom">Columns</v-tooltip>
    </v-btn>
  </template>
  <v-list density="compact" max-height="400">
    <v-list-subheader>Visible Columns</v-list-subheader>
    <v-list-item v-for="column in columns" :key="column.key" @click="emit('toggle:column', column.key)">
      <template #prepend>
        <v-checkbox-btn :model-value="visibleColumns.includes(column.key)" hide-details readonly />
      </template>
      <v-list-item-title>{{ column.title }}</v-list-item-title>
    </v-list-item>
    <v-divider class="my-2" />
    <v-list-item prepend-icon="mdi-refresh" title="Reset to Defaults" @click="emit('reset')" />
  </v-list>
</v-menu>
```

Use @click.stop on checkbox to prevent menu close on toggle.

  <name>Task 2: Integrate column preferences into VariantTable</name>
  <files>src/renderer/src/components/VariantTable.vue</files>
  <action>
Enhance VariantTable to use useColumnPreferences for column visibility and order.

1. Import useColumnPreferences and ColumnVisibilityMenu:
   ```typescript
   import { useColumnPreferences } from '../composables/useColumnPreferences'
   import ColumnVisibilityMenu from './ColumnVisibilityMenu.vue'
   ```

2. Initialize preferences:
   ```typescript
   const { prefs, resetToDefaults, toggleColumnVisibility } = useColumnPreferences('variant-table')
   ```

3. Create computed `visibleHeaders` that filters and reorders headers based on prefs:
   ```typescript
   const visibleHeaders = computed(() => {
     const base = headers.value
     // Filter by visibility (default to visible if not in prefs)
     const visible = base.filter(h => prefs.value.visibility[h.key] !== false)
     // Sort by order if order array is non-empty
     if (prefs.value.order.length > 0) {
       return [...visible].sort((a, b) => {
         const aIdx = prefs.value.order.indexOf(a.key)
         const bIdx = prefs.value.order.indexOf(b.key)
         // Items not in order array go to end
         if (aIdx === -1 && bIdx === -1) return 0
         if (aIdx === -1) return 1
         if (bIdx === -1) return -1
         return aIdx - bIdx
       })
     }
     return visible
   })
   ```

4. Use `visibleHeaders` instead of `headers` in v-data-table-server `:headers` prop.

5. Add ColumnVisibilityMenu in a toolbar row above the table or in a slot:
   - Add a div above the table with class "d-flex justify-end pa-2"
   - Include ColumnVisibilityMenu with columns from baseHeaders (all columns)
   - Handle @toggle:column -> toggleColumnVisibility
   - Handle @reset -> resetToDefaults

6. Add CSS for column max-width with ellipsis. In the existing style section, add:
   ```css
   :deep(.v-data-table th),
   :deep(.v-data-table td) {
     max-width: 200px;
     overflow: hidden;
     text-overflow: ellipsis;
     white-space: nowrap;
   }
   ```

Note: The table already has tooltip handling for long allele values. This CSS applies globally to all cells as a fallback.
