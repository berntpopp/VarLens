Create composable that provides reactive column preference state using VueUse's useStorage.

Interface:
```typescript
interface ColumnPreferences {
  order: string[]                    // Column keys in user's preferred order (empty = default)
  visibility: Record<string, boolean> // Column key -> visible (missing = visible by default)
  widths: Record<string, number>     // Column key -> width in pixels (missing = default)
}
```

Export a function `useColumnPreferences(tableId: string)` that returns:
- `prefs: Ref<ColumnPreferences>` - reactive preferences object (auto-syncs to localStorage)
- `resetToDefaults: () => void` - clears all preferences to defaults
- `setColumnOrder: (keys: string[]) => void` - updates order
- `toggleColumnVisibility: (key: string) => void` - toggle visibility
- `setColumnWidth: (key: string, width: number) => void` - set width with min/max clamping

LocalStorage key format: `varlens_columns_${tableId}` (use underscore to match existing varlens_panel_width convention).

Use `mergeDefaults: true` in useStorage options to handle schema evolution when new properties are added.

Clamp widths to min 60px, max 500px.

  <action>
Create composable that provides reactive filter group preference state.

Interface:
```typescript
interface FilterGroupPreference {
  id: string           // e.g., 'search', 'gene', 'impact', 'function', 'clinvar', 'frequency', 'cadd', 'tags'
  order: number        // Display order (lower = left)
  active: boolean      // Whether filter group is expanded/active (collapsed saves space)
}

interface FilterPreferences {
  groups: FilterGroupPreference[]
}
```

Export a function `useFilterPreferences()` that returns:
- `filterGroups: ComputedRef<FilterGroupPreference[]>` - sorted by order
- `setFilterGroupOrder: (ids: string[]) => void` - reorder groups
- `toggleFilterGroupActive: (id: string) => void` - toggle active/collapsed state
- `resetToDefaults: () => void` - restore default order and all active

Default filter groups (in order):
1. search - "Search"
2. gene - "Gene"
3. impact - "Impact"
4. function - "Function"
5. clinvar - "ClinVar"
6. frequency - "Frequency"
7. cadd - "CADD"
8. tags - "Tags"

LocalStorage key: `varlens_filter_groups`

If stored groups are missing any default IDs (e.g., new filter added in future), merge them at the end with active=true.
