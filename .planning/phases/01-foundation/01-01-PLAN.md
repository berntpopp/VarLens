  <files>
    package.json

    src/renderer/src/App.vue
    src/renderer/src/env.d.ts
  </files>
  <action>
    1. Create project using electron-vite Vue template:
       ```bash
       npm create @quick-start/electron@latest . -- --template vue-ts
       ```
       Note: Use `.` to scaffold in current directory since it already exists.

    2. After scaffolding, modify `src/main/index.ts`:
       - Set window size to 1440x900
       - Set window title to "Varlens"
       - Add single instance lock with `app.requestSingleInstanceLock()`
       - Open DevTools automatically when `process.env.NODE_ENV === 'development'`
       - Ensure webPreferences has: contextIsolation: true, nodeIntegration: false, sandbox: true

    3. Modify `electron.vite.config.ts`:
       - Add `externalizeDepsPlugin()` to main config
       - Add `better-sqlite3` to rollupOptions.external array
       - This prevents Vite from bundling native modules

    4. Update `package.json`:
       - Set name to "varlens"
       - Set version to "0.1.0"
       - Add electron-builder config with:
         - appId: "com.varlens.app"
         - productName: "Varlens"
         - asarUnpack: ["**/*.node"]
         - files: ["out/**/*", "node_modules/better-sqlite3/**/*"]
         - Platform targets for mac (dmg, zip), win (nsis, zip), linux (AppImage, deb)
       - Add postinstall script: "electron-builder install-app-deps"

    5. Configure TypeScript strictly in `tsconfig.json`:
       - strict: true
       - strictNullChecks: true
       - noImplicitAny: true
       - noUnusedLocals: true
       - noUnusedParameters: true
  </action>
  <verify>
    Run `npm install` completes without errors.
    Run `npm run dev` starts the application (will fail on Vuetify but Electron window should attempt to open).
  </verify>
  <done>
    Project structure exists with electron-vite configuration. Main process configured for single instance with correct window size and title.
  </done>
</task>
