Create VariantTable.vue component with Vuetify v-data-table-server implementing:

**Props:**
- `caseId: number` - Required prop for which case to display

**State (refs):**
- `variants: Variant[]` - Current page data
- `totalCount: number` - Total variant count for pagination
- `loading: boolean` - Loading state for spinner overlay
- `page: number` - Current page (v-model binding)
- `itemsPerPage: number` - Items per page, default 50 (v-model binding)
- `sortBy: SortItem[]` - Sort configuration (v-model binding)
- `cursorCache: Map<number, PaginationCursor>` - Cache cursors for page navigation

**Headers definition:**
Define headers array with all 9 columns:
- chr (sortable, title "Chr")
- pos (sortable, title "Position", align end)
- ref (not sortable, title "Ref", width 120px)
- alt (not sortable, title "Alt", width 120px)
- gene_symbol (sortable, title "Gene")
- consequence (sortable, title "Consequence")
- gnomad_af (sortable, title "gnomAD AF", align end)
- cadd (sortable, title "CADD", align end)
- clinvar (sortable, title "ClinVar")

**loadVariants function:**
- Triggered by @update:options event
- Set loading = true
- Get cursor from cursorCache for page > 1, undefined for page 1
- Call window.api.variants.query(props.caseId, {}, cursor, itemsPerPage)
- Update variants and totalCount from result
- Cache next_cursor if has_more is true
- Set loading = false in finally block
- Handle errors with console.error and reset variants/totalCount

**Watch effect:**
- Watch props.caseId changes
- Clear cursorCache
- Reset page to 1

**Template structure:**
```vue
<v-data-table-server
  :headers="headers"
  :items="variants"
  :items-length="totalCount"
  :loading="loading"
  v-model:page="page"
  v-model:items-per-page="itemsPerPage"
  v-model:sort-by="sortBy"
  :items-per-page-options="[25, 50, 100]"
  @update:options="loadVariants"
  density="compact"
  multi-sort
  class="elevation-1"
>
  <!-- Column slots added in Task 2 -->
</v-data-table-server>
```

**Important anti-patterns to avoid (from research):**
- Do NOT mutate page, itemsPerPage, or sortBy inside loadVariants handler (causes infinite loop)
- Only mutate variants, totalCount, loading inside the handler
- Do NOT use async/await without try/catch/finally pattern

Add ESLint disable comment for window.api (pattern from Phase 5).

**Add formatting functions to VariantTable.vue:**

```typescript
// Position formatting with thousand separators
const formatPosition = (pos: number): string => {
  return new Intl.NumberFormat('en-US').format(pos)
}

// Scientific notation for gnomAD AF
const formatScientific = (value: number | null): string => {
  if (value === null) return '-'
  if (value < 0.001 && value > 0) {
    return new Intl.NumberFormat('en-US', {
      notation: 'scientific',
      maximumFractionDigits: 1
    }).format(value)
  }
  return new Intl.NumberFormat('en-US', {
    maximumFractionDigits: 4
  }).format(value)
}

// ClinVar color mapping (clinical conventions)
const getClinVarColor = (significance: string | null): string => {
  if (!significance) return 'grey'
  const colorMap: Record<string, string> = {
    'Pathogenic': 'red',
    'Likely_pathogenic': 'red-lighten-1',
    'Uncertain_significance': 'amber',
    'Likely_benign': 'green-lighten-1',
    'Benign': 'green'
  }
  return colorMap[significance] || 'grey'
}
```

**Add template slots for formatted columns:**

```vue
<!-- Position with thousand separators -->
<template v-slot:item.pos="{ value }">
  {{ formatPosition(value) }}
</template>

<!-- gnomAD AF in scientific notation -->
<template v-slot:item.gnomad_af="{ value }">
  {{ formatScientific(value) }}
</template>

<!-- ClinVar colored chips -->
<template v-slot:item.clinvar="{ value }">
  <v-chip
    v-if="value"
    :color="getClinVarColor(value)"
    size="small"
    label
  >
    {{ value.replace(/_/g, ' ') }}
  </v-chip>
  <span v-else class="text-grey">-</span>
</template>

<!-- Ref allele with truncation and tooltip -->
<template v-slot:item.ref="{ value }">
  <v-tooltip v-if="value.length > 20" location="top">
    <template v-slot:activator="{ props }">
      <span v-bind="props" class="text-truncate allele-cell">
        {{ value.substring(0, 20) }}...
      </span>
    </template>
    <span class="font-mono">{{ value }}</span>
  </v-tooltip>
  <span v-else class="font-mono">{{ value }}</span>
</template>

<!-- Alt allele with truncation and tooltip (same pattern) -->
<template v-slot:item.alt="{ value }">
  <v-tooltip v-if="value.length > 20" location="top">
    <template v-slot:activator="{ props }">
      <span v-bind="props" class="text-truncate allele-cell">
        {{ value.substring(0, 20) }}...
      </span>
    </template>
    <span class="font-mono">{{ value }}</span>
  </v-tooltip>
  <span v-else class="font-mono">{{ value }}</span>
</template>

<!-- CADD score (handle null) -->
<template v-slot:item.cadd="{ value }">
  {{ value !== null ? value.toFixed(1) : '-' }}
</template>

<!-- Gene symbol (handle null) -->
<template v-slot:item.gene_symbol="{ value }">
  {{ value || '-' }}
</template>

<!-- Consequence (handle null) -->
<template v-slot:item.consequence="{ value }">
  {{ value ? value.replace(/_/g, ' ') : '-' }}
</template>
```
