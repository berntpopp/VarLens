  <action>
Add the following methods to DatabaseService class:

1. **getGlobalAnnotation(chr, pos, ref, alt)**: Returns VariantAnnotation | null
   - Use prepared statement cache pattern (this.stmt())
   - Query variant_annotations by composite key

2. **upsertGlobalAnnotation(chr, pos, ref, alt, updates)**: Returns VariantAnnotation
   - Use INSERT ON CONFLICT DO UPDATE (atomic upsert, no race conditions)
   - updates is Partial<Pick<VariantAnnotation, 'global_comment' | 'starred' | 'acmg_classification' | 'acmg_evidence'>>
   - Use COALESCE to only update non-null fields in updates
   - Set updated_at = Date.now() on every upsert
   - Convert boolean starred to 0/1 before write
   - Use RETURNING * to get the upserted row

3. **deleteGlobalAnnotation(chr, pos, ref, alt)**: void
   - DELETE from variant_annotations
   - No error if not found (idempotent)

4. **getPerCaseAnnotation(caseId, variantId)**: Returns CaseVariantAnnotation | null
   - Query case_variant_annotations by case_id + variant_id

5. **upsertPerCaseAnnotation(caseId, variantId, updates)**: Returns CaseVariantAnnotation
   - updates is Partial<Pick<CaseVariantAnnotation, 'per_case_comment'>>
   - Use INSERT ON CONFLICT DO UPDATE
   - Per-case starred stored here if needed (context says both global + per-case star exist)
   - Set updated_at = Date.now()
   - Use RETURNING *

6. **deletePerCaseAnnotation(caseId, variantId)**: void
   - DELETE from case_variant_annotations
   - Idempotent

7. **getAnnotationsForVariant(caseId, chr, pos, ref, alt)**: Returns combined object
   - Returns { global: VariantAnnotation | null, perCase: CaseVariantAnnotation | null }
   - Single method for UI to get all annotations for a variant in context
   - Find variant_id by case_id + chr + pos + ref + alt (JOIN variants table)

Key implementation notes from RESEARCH.md:
- Use INSERT ON CONFLICT (SQLite 3.24.0+) to avoid race conditions
- Always set updated_at = Date.now() on updates
- Convert boolean to 0/1 for starred column (SQLite INTEGER)
- ACMG evidence stored as JSON.stringify(AcmgEvidence)
- Import CaseVariantAnnotation type from ./types
