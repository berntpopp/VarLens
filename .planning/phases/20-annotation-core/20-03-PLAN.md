  <name>Task 1: Add comment getter and mutation methods to useAnnotations</name>
  <files>src/renderer/src/composables/useAnnotations.ts</files>
  <action>
Add these methods to the useAnnotations composable:

1. **getGlobalComment(chr, pos, ref, alt)**: Returns string | null from cache.global?.global_comment

2. **getPerCaseComment(chr, pos, ref, alt)**: Returns string | null from cache.perCase?.per_case_comment

3. **upsertGlobalComment(chr, pos, ref, alt, comment: string | null)**:
   - Optimistic update: Update cache.global.global_comment immediately
   - Call window.api.annotations.upsertGlobal with { global_comment: comment }
   - On success: Update cache with server response
   - On failure: Revert optimistic update, console.error
   - Return Promise<void>

4. **upsertPerCaseComment(caseId, chr, pos, ref, alt, comment: string | null)**:
   - Need variant_id for per-case operations. Since we don't have it in cache, call getForVariant first to ensure cache is populated, then use a new IPC call.
   - ISSUE: The existing IPC takes variantId, but we have chr:pos:ref:alt.
   - SOLUTION: Add a helper that first looks up variant_id via a new method, OR use the fact that getAnnotationsForVariant returns perCase which has variant_id in it.
   - Actually, CaseVariantAnnotation has variant_id field. So: load annotations first if not cached, then use perCase.variant_id OR if no perCase exists yet, we need to get variant_id from variants table.
   - SIMPLIFICATION: For now, require that loadAnnotations was called first. If perCase is null and we're creating new, we need variant_id. Add a getVariantId IPC or include variant_id in the getAnnotationsForVariant response.
   - ALTERNATIVE: Pass variant_id as parameter to upsertPerCaseComment. The caller (VariantTable) has access to item.id which is the variant_id.

   Signature: upsertPerCaseComment(caseId: number, variantId: number, chr: string, pos: number, ref: string, alt: string, comment: string | null)
   - Optimistic update: Update cache perCase.per_case_comment
   - Call window.api.annotations.upsertPerCase(caseId, variantId, { per_case_comment: comment })
   - On success: Update cache
   - On failure: Revert, console.error

5. **deleteGlobalComment(chr, pos, ref, alt)**:
   - Set cache.global.global_comment to null optimistically
   - Call upsertGlobal with { global_comment: null } (NOT deleteGlobal, which deletes entire annotation including star/ACMG)
   - This preserves other fields while clearing comment

6. **deletePerCaseComment(caseId, variantId, chr, pos, ref, alt)**:
   - Similar to deleteGlobalComment but for per-case
   - Call upsertPerCase with { per_case_comment: null }

Export all new methods from the composable return object.
