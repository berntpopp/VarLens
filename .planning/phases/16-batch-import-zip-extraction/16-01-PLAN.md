    ```typescript
    export type BatchFileStatus = 'pending' | 'importing' | 'success' | 'failed' | 'skipped'

      fileName: string
      status: BatchFileStatus
      caseName?: string
      variantCount?: number
      error?: string

      onDuplicatePrompt: (callback: (prompt: DuplicatePrompt) => void) => () => void
      resolveDuplicate: (choice: DuplicateChoice, applyToAll: boolean) => Promise<void>
    }
    ```

    ```typescript
      onFileProgress?: ProgressCallback
      onDuplicateFound?: (fileName: string, caseName: string) => Promise<{ choice: DuplicateChoice; applyToAll: boolean }>
    ```

    **3. Create BatchImportService** (`src/main/import/BatchImportService.ts`):

    Create a class that:
    - Constructor takes `DatabaseService` and `ImportService`
    - Has method `async processBatch(filePaths: string[], options: BatchImportOptions): Promise<BatchResult>`
    - Processes files sequentially in a for-loop
    - For each file:
      a. Extract case name from filename (strip .json.gz / .gz extensions)
      b. Check for duplicate: query `db.getCaseByName(caseName)` wrapped in try-catch (NotFoundError means no duplicate)
      c. Also check in-memory Set of case names imported in this batch (prevents race condition from Pitfall 4 in RESEARCH.md)
      d. If duplicate found: call `onDuplicateFound` callback. If no callback or user chose 'skip', mark as skipped and continue. If 'overwrite', delete existing case first via `db.deleteCase(existingCase.id)`
      e. Track `applyToAll` state: once user checks it, apply same choice to all remaining duplicates without prompting
      f. Call `importService.importVariants(filePath, { caseName, onProgress: options.onFileProgress, signal: options.signal })`
      g. On success: record in details array with status 'success', caseName, variantCount
      h. On error (catch around importVariants): record with status 'failed' and error message. DO NOT rethrow -- continue to next file
      i. Check `signal?.aborted` before each file; if aborted, break the loop and mark remaining files as 'skipped' with reason 'cancelled'
    - Returns `BatchResult` with counts and details array
    - Emits progress via `onBatchProgress` callback: currentIndex, totalFiles, fileName, overallPercent (calculated as `Math.round(((currentIndex) / totalFiles) * 100)`)

    Case name extraction logic: take filename, strip path, remove `.gz` suffix, remove `.json` suffix, result is case name. Match the pattern in existing ImportDialog.vue `extractCaseName`.

    **5. Create batch-import IPC handlers** (`src/main/ipc/handlers/batch-import.ts`):

    Follow the pattern in `import.ts`. Register these channels:

    - `batch-import:selectFiles` -- Opens Electron dialog with `properties: ['openFile', 'multiSelections']`, filters for JSON/gz files AND ZIP archives. Returns `string[]` of selected file paths. Saves last directory to settings (reuse the settings pattern from import.ts).

    - `batch-import:selectFolder` -- Opens Electron dialog with `properties: ['openDirectory']`. Reads the selected directory with `readdirSync({ withFileTypes: true })`, filters for top-level files matching `.json.gz`, `.gz`, or `.json` extensions. Returns full paths as `string[]`. If no matching files found, returns empty array.

    - `batch-import:start` -- Accepts `filePaths: string[]`. Creates BatchImportService with current DB and ImportService. Sets up:
      - AbortController for cancellation (stored in module-level variable like existing import.ts)
      - Throttled batch progress emitter (100ms interval) that sends `batch-import:progress` to renderer
      - Throttled file progress emitter that sends per-file variant counts as part of batch progress
      - Duplicate prompt handler: sends `batch-import:duplicatePrompt` to renderer and WAITS for response via a Promise that resolves when `batch-import:resolveDuplicate` is called
      - Returns `BatchResult` via wrapHandler

    - `batch-import:cancel` -- Aborts the current AbortController

    - `batch-import:resolveDuplicate` -- Accepts `choice: DuplicateChoice, applyToAll: boolean`. Resolves the pending duplicate promise.

    For the duplicate prompt/resolve pattern: Use a module-level variable `let pendingDuplicateResolve: ((value: { choice: DuplicateChoice; applyToAll: boolean }) => void) | null = null`. When a duplicate is found, the onDuplicateFound callback creates a new Promise and stores the resolve function. When `batch-import:resolveDuplicate` is called, it invokes the stored resolve.

    ```typescript
    batchImport: {
      selectFiles: () => ipcRenderer.invoke('batch-import:selectFiles'),
      selectFolder: () => ipcRenderer.invoke('batch-import:selectFolder'),
      start: (filePaths: string[]) => ipcRenderer.invoke('batch-import:start', filePaths),
      cancel: () => ipcRenderer.invoke('batch-import:cancel'),
      onProgress: (callback: (progress: BatchProgress) => void): (() => void) => {
        const handler = (_event: Electron.IpcRendererEvent, progress: BatchProgress) => {
          callback(progress)
        }
        ipcRenderer.on('batch-import:progress', handler)
        return () => { ipcRenderer.removeListener('batch-import:progress', handler) }
      },
      onDuplicatePrompt: (callback: (prompt: DuplicatePrompt) => void): (() => void) => {
        const handler = (_event: Electron.IpcRendererEvent, prompt: DuplicatePrompt) => {
          callback(prompt)
        }
        ipcRenderer.on('batch-import:duplicatePrompt', handler)
        return () => { ipcRenderer.removeListener('batch-import:duplicatePrompt', handler) }
      },
      resolveDuplicate: (choice: DuplicateChoice, applyToAll: boolean) =>
        ipcRenderer.invoke('batch-import:resolveDuplicate', choice, applyToAll)
    }
    ```

    **1. Create BatchImportDialog.vue** (`src/renderer/src/components/BatchImportDialog.vue`):

    A Vuetify 3 modal dialog with four views managed by a reactive `phase` state: 'idle' | 'importing' | 'duplicate-prompt' | 'summary'.

    **Structure:**
    ```
    v-dialog (max-width="650", persistent when importing)
      v-card
        v-card-title: "Batch Import"
        v-card-text:
          [Phase: idle] -- Not visible (dialog opens directly into importing)
          [Phase: importing] -- Progress view
          [Phase: duplicate-prompt] -- Inline duplicate decision
          [Phase: summary] -- Results report
        v-card-actions:
          Cancel/Close button
    ```

    **Importing phase UI:**
    - Text: "Importing {currentFileName} ({currentIndex + 1} of {totalFiles})"
    - v-progress-linear with :model-value="overallPercent", color="primary", height="25", shows percentage text via default slot
    - Below progress bar: "Variants processed: {variantCount}" (from per-file progress)

    **Duplicate prompt phase UI:**
    - v-alert type="warning": "A case named '{caseName}' already exists."
    - Text: "File: {fileName}"
    - v-checkbox: "Apply this choice to all remaining duplicates" (v-model bound to applyToAll ref)
    - Two buttons: "Skip" (outlined) and "Overwrite" (color="warning")
    - When user clicks either: call `window.api.batchImport.resolveDuplicate(choice, applyToAll)` and set phase back to 'importing'

    **Summary phase UI:**
    - Three v-chip components showing counts: succeeded (color="success"), failed (color="error"), skipped (color="secondary")
    - If cancelled: v-alert type="info" text="Import was cancelled. {succeeded} files were imported before cancellation."
    - v-expansion-panels (variant="accordion") with one panel per file in details:
      - Panel title: icon (mdi-check-circle color="success" | mdi-alert-circle color="error" | mdi-skip-next color="secondary") + fileName + optional variant count for success
      - Panel text (for failed): error message
      - Panel text (for success): "Case: {caseName}, {variantCount} variants imported"
      - Panel text (for skipped): "Skipped (duplicate)" or "Skipped (cancelled)"

    **Component logic:**
    - `show(mode: 'files' | 'folder')` method exposed via defineExpose:
      - If mode === 'files': call `window.api.batchImport.selectFiles()`. If empty array returned, close dialog and return.
      - If mode === 'folder': call `window.api.batchImport.selectFolder()`. If empty array, show snackbar "No JSON.gz files found in folder" and return.
      - Set dialog=true, phase='importing', start import
    - `startImport(filePaths)`: call `window.api.batchImport.start(filePaths)`. When promise resolves, set summary data and phase='summary'.
    - Progress listener: `onMounted` register `window.api.batchImport.onProgress(callback)`, store cleanup. Update reactive progress refs.
    - Duplicate listener: `onMounted` register `window.api.batchImport.onDuplicatePrompt(callback)`. When received, set phase='duplicate-prompt' with prompt data.
    - Cancel handler: if importing, call `window.api.batchImport.cancel()`. Otherwise close dialog.
    - Cleanup: `onUnmounted` call both listener cleanup functions.
    - Emit `'batch-import-complete'` event with `{ totalImported: number }` when dialog closes after successful summary.

    **Important UI notes:**
    - Use Vuetify's warm palette: primary color for progress, secondary for skipped
    - Follow existing dialog patterns from ImportDialog.vue: v-dialog + v-card structure
    - Persistent dialog during import (user cannot dismiss by clicking outside)
    - Use `<script setup lang="ts">` with Composition API
    - Use `defineEmits` and `defineExpose` following existing patterns
