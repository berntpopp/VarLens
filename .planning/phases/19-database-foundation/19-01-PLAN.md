Create new file `src/main/database/migrations.ts` implementing schema migration using PRAGMA user_version.

Structure:
```typescript
import type Database from 'better-sqlite3-multiple-ciphers'

/**
 * Run schema migrations based on PRAGMA user_version
 *
 * Migrations are idempotent and safe for both plaintext and encrypted databases.
 * IMPORTANT: This function must be called AFTER PRAGMA key is issued for encrypted DBs.
 */
export function runMigrations(db: Database.Database): void {
  const result = db.prepare('PRAGMA user_version').get() as { user_version: number }
  const currentVersion = result.user_version

  // v0.3.0 baseline - existing databases have no version set
  if (currentVersion < 1) {
    // Mark existing v0.3.0 schema as version 1
    db.exec('PRAGMA user_version = 1')
  }

  // v0.4.0 annotation tables
  if (currentVersion < 2) {
    // Create all v0.4.0 tables...
    db.exec('PRAGMA user_version = 2')
  }
}
```

Tables to create in migration version 2:

1. **variant_annotations** - Global variant annotations
   - UNIQUE(chr, pos, ref, alt) for lookup by coordinates
   - No foreign key to variants table (annotations persist even if variant deleted in one case)

2. **case_variant_annotations** - Per-case annotations
   - FK to cases(id) ON DELETE CASCADE
   - FK to variants(id) ON DELETE CASCADE
   - UNIQUE(case_id, variant_id)

3. **case_metadata** - Case status and notes
   - FK to cases(id) ON DELETE CASCADE
   - UNIQUE case_id (one metadata row per case)

4. **cohort_groups** - Cohort definitions
   - UNIQUE name

5. **case_cohort_links** - Case-cohort junction
   - FK to cases(id) ON DELETE CASCADE
   - FK to cohort_groups(id) ON DELETE CASCADE
   - UNIQUE(case_id, cohort_id)

6. **api_cache** - API response cache
   - UNIQUE cache_key
   - INDEX on expires_at for cleanup queries

7. **tags** - Custom tag definitions
   - UNIQUE name

8. **variant_tags** - Per-case tag assignments
   - FK to cases(id) ON DELETE CASCADE
   - FK to variants(id) ON DELETE CASCADE
   - FK to tags(id) ON DELETE CASCADE
   - UNIQUE(case_id, variant_id, tag_id)

9. **case_hpo_terms** - HPO term assignments
   - FK to cases(id) ON DELETE CASCADE
   - UNIQUE(case_id, hpo_id)

Use CREATE TABLE IF NOT EXISTS for idempotency. Use parameterized CREATE INDEX IF NOT EXISTS.

Add JSDoc comment explaining that migrations run AFTER PRAGMA key in DatabaseService constructor.
