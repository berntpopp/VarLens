    **1. Extend CohortService in `src/main/database/cohort.ts`** with three new methods:

    **`getCarriers(chr: string, pos: number, ref: string, alt: string): CohortCarrier[]`**
    - Query: `SELECT v.case_id, c.name as case_name, v.gt_num FROM variants v JOIN cases c ON v.case_id = c.id WHERE v.chr = ? AND v.pos = ? AND v.ref = ? AND v.alt = ? ORDER BY c.name`
    - Returns array of `CohortCarrier` objects (case_id, case_name, gt_num)
    - Uses parameterized binding

    **`searchCohortVariants(params: CohortSearchParams): { data: CohortVariant[], total_count: number }`**
    - Modify the existing `getCohortVariants` method (or create a search variant) to support the `search_term` parameter from `CohortSearchParams`.
    - Implement hybrid search strategy based on search term pattern detection:
      - Gene symbol (`/^[A-Z][A-Z0-9]+$/i`): Use FTS5 via subquery: `WHERE id IN (SELECT rowid FROM variants_fts WHERE gene_symbol MATCH ?)`. Escape FTS5 special characters: if term contains `-`, `*`, or `"`, wrap in double quotes with internal quote escaping (`"BRCA-1"` not `BRCA-1`). Append `*` for prefix matching.
      - Genomic position (`/^(?:chr)?(\d{1,2}|X|Y|MT?):(\d+)$/i`): Extract chr and pos, filter with `WHERE chr = ? AND pos = ?`. Normalize chr by stripping `chr` prefix.
      - HGVS notation (`/^[cp]\./`): Use `WHERE (cdna LIKE ? OR aa_change LIKE ?)` with `%term%` wrapping.
      - Fallback: `WHERE (gene_symbol LIKE ? OR cdna LIKE ? OR aa_change LIKE ?)` with `%term%` wrapping.
    - The search filtering is applied BEFORE GROUP BY (it filters which variant rows participate in aggregation).
    - When `search_term` is empty/undefined, behave identically to `getCohortVariants` from Plan 01.
    - IMPORTANT: Merge search functionality into the existing `getCohortVariants` method rather than creating a separate method. The search_term is just another filter parameter.

    **`getGeneBurden(): GeneBurden[]`**
    - Query:
      ```sql
      SELECT
        gene_symbol,
        COUNT(*) as variant_count,
        COUNT(DISTINCT chr || ':' || pos || ':' || ref || ':' || alt) as unique_variant_count,
        COUNT(DISTINCT case_id) as affected_case_count,
        (SELECT COUNT(*) FROM cases) as total_cases
      FROM variants
      WHERE gene_symbol IS NOT NULL AND gene_symbol != ''
      GROUP BY gene_symbol
      ORDER BY affected_case_count DESC, variant_count DESC
      ```
    - Only returns genes with actual variant hits (WHERE gene_symbol IS NOT NULL filters empty genes).
    - Returns all genes (no pagination needed -- gene count is bounded by genome).
