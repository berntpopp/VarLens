  <action>
    **1. Create `src/shared/types/cohort.ts`** with these TypeScript interfaces:

    - `CohortVariant`: `{ chr: string, pos: number, ref: string, alt: string, gene_symbol: string | null, carrier_count: number, total_cases: number, cohort_frequency: number, het_count: number, hom_count: number, variant_key: string }` where `variant_key` is `"chr:pos:ref:alt"` composite string for stable v-data-table item-value tracking.
    - `CohortCarrier`: `{ case_id: number, case_name: string, gt_num: string }` for per-variant drill-down (used in Plan 02).
    - `CohortSummary`: `{ total_cases: number, total_variants: number, unique_variants: number, avg_variants_per_case: number, genes_with_variants: number }` for dashboard stats.
    - `GeneBurden`: `{ gene_symbol: string, variant_count: number, unique_variant_count: number, affected_case_count: number, total_cases: number }` for gene-level aggregation (used in Plan 02).
    - `CohortSearchParams`: `{ search_term?: string, sort_by?: string, sort_order?: 'asc' | 'desc', limit?: number, offset?: number }` for paginated cohort queries.

    **2. Create `src/main/database/cohort.ts`** with a `CohortService` class:

    - Constructor takes a `Database.Database` instance (from `better-sqlite3-multiple-ciphers`).
    - `getCohortVariants(params: CohortSearchParams)`: Returns `{ data: CohortVariant[], total_count: number }`. Uses GROUP BY (chr, pos, ref, alt) with:
      - `COUNT(DISTINCT case_id)` as carrier_count
      - `COUNT(DISTINCT case_id) * 1.0 / total_cases` as cohort_frequency
      - `SUM(CASE WHEN gt_num IN ('0/1', '1/0', '0|1', '1|0') THEN 1 ELSE 0 END)` as het_count
      - `SUM(CASE WHEN gt_num IN ('1/1', '1|1') THEN 1 ELSE 0 END)` as hom_count
      - Include `gene_symbol` via `MAX(gene_symbol)` (same variant always has same gene)
      - Build `variant_key` as `chr || ':' || pos || ':' || ref || ':' || alt` in SQL
      - Default ORDER BY `carrier_count DESC, pos ASC`
      - Support dynamic sort via allowlisted column map (similar to SORTABLE_COLUMNS pattern in DatabaseService.ts): `{ chr: 'chr', pos: 'pos', gene_symbol: 'gene_symbol', carrier_count: 'carrier_count', cohort_frequency: 'cohort_frequency', het_count: 'het_count', hom_count: 'hom_count' }`
      - Use LIMIT/OFFSET pagination (not cursor -- GROUP BY makes cursor pagination complex)
      - Run a separate COUNT query (same GROUP BY without LIMIT) for total_count
    - `getCohortSummary()`: Returns `CohortSummary`. Single query using:
      - `SELECT COUNT(*) FROM cases` for total_cases
      - `SELECT COUNT(*) FROM variants` for total_variants
      - `SELECT COUNT(DISTINCT chr || ':' || pos || ':' || ref || ':' || alt) FROM variants` for unique_variants
      - Compute avg_variants_per_case = total_variants / total_cases (handle division by zero)
      - `SELECT COUNT(DISTINCT gene_symbol) FROM variants WHERE gene_symbol IS NOT NULL` for genes_with_variants
    - Use prepared statement caching pattern: store statements in a Map keyed by SQL string (following DatabaseService.ts pattern).
    - All queries use parameterized binding (no string interpolation for user values).

    **3. Update `src/main/database/schema.ts`**:

    - Add a new composite index to the `createIndexes` constant:
      ```sql
      CREATE INDEX IF NOT EXISTS idx_variants_chr_pos_ref_alt ON variants(chr, pos, ref, alt);
      ```
    - This index is CRITICAL for GROUP BY performance on cohort aggregation queries. Without it, SQLite creates a temp B-tree (100x slower).

    **4. Create `src/main/ipc/handlers/cohort.ts`**:

    Follow the exact pattern from `src/main/ipc/handlers/variants.ts`:
    - Import `ipcMain` from `electron`, `wrapHandler` from `../errorHandler`, `getDatabaseService` from `../../database`.
    - Import `CohortService` from `../../database/cohort`.
    - Import types from `../../../shared/types/cohort`.
    - Channel `cohort:variants`: Takes `CohortSearchParams`, creates `CohortService(getDatabaseService().database)`, calls `getCohortVariants(params)`, returns `{ data: CohortVariant[], total_count: number }`.
    - Channel `cohort:summary`: No params, creates `CohortService(getDatabaseService().database)`, calls `getCohortSummary()`, returns `CohortSummary`.
    - Wrap both in `wrapHandler`.

    **5. Register cohort handlers in `src/main/ipc/index.ts`**:

    Add `import('./handlers/cohort')` to the `Promise.all` array in `registerIpcHandlers()`.

    **6. Extend preload API in `src/preload/index.ts`**:

    Add a `cohort` namespace to the `api` object following the existing pattern:
    ```typescript
    cohort: {
      getVariants: (params: CohortSearchParams) =>
        ipcRenderer.invoke('cohort:variants', params),
      getSummary: () =>
        ipcRenderer.invoke('cohort:summary')
    }
    ```
    Import `CohortSearchParams` from shared types.

    **7. Update `src/preload/index.d.ts`** if it exists (or add CohortAPI to `src/shared/types/api.ts`):

    Add `CohortAPI` interface to `src/shared/types/api.ts`:

    ```typescript
      getVariants: (params: CohortSearchParams) => Promise<{ data: CohortVariant[], total_count: number }>
      getSummary: () => Promise<CohortSummary>
    }
    ```
    Add `cohort: CohortAPI` to the `WindowAPI` interface.
    Import cohort types from `./cohort` or inline them.

      - `{ title: 'Alt', key: 'alt', sortable: false }`
      - `{ title: 'Gene', key: 'gene_symbol', sortable: true }`
      - `{ title: 'Carriers', key: 'carrier_count', sortable: true, align: 'end' }`
      - `{ title: 'Frequency', key: 'cohort_frequency', sortable: true, align: 'end' }`
      - `{ title: 'Het / Hom', key: 'het_count', sortable: true }`
    - Use `v-data-table-server` with:
      - `:items="cohortVariants"` (reactive ref)
      - `:headers="headers"`
      - `:items-length="totalCount"` (for server-side pagination)
      - `:items-per-page="50"` default
      - `:items-per-page-options="[25, 50, 100]"`
      - `item-value="variant_key"` (stable key from SQL)

    - `handleTableOptions(options)` extracts `page`, `itemsPerPage`, `sortBy` from Vuetify's options event:

      - Extract sort from `sortBy[0]` if present (key and order)
      - Call `loadCohortVariants()` with new params
    - Call `loadCohortVariants()` on mount via `onMounted`
