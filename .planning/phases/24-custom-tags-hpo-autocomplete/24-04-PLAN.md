// Filter by tag IDs (OR logic - variants with ANY of the selected tags)
if (filter.tag_ids !== undefined && filter.tag_ids.length > 0) {

Key implementation notes:
- Uses a subquery (IN SELECT) rather than JOIN to avoid duplicate rows and maintain existing query structure
- Filters by case_id in the subquery to ensure per-case tag isolation
- OR logic means variants with ANY selected tag are returned
- Empty array or undefined tag_ids means no tag filter is applied (backwards compatible)
