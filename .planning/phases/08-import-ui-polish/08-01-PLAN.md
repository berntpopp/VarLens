Create ImportDialog.vue following DeleteCaseDialog.vue pattern with defineExpose:

**Template structure:**
- v-dialog with v-model="dialog", max-width="500", :persistent="isImporting"
- v-card with title "Import Variant Data"
- v-card-text containing:
  - File display: show selected file path (read-only text field or text display)
  - Browse button: triggers window.api.import.selectFile(), updates filePath ref
  - v-text-field for case name with :rules validation (required, 3-50 chars)
  - v-alert for error display (v-if="errorMessage", type="error")
  - Progress section (v-if="isImporting"):
    - v-progress-linear with indeterminate mode (backend doesn't provide total)
    - Text showing phase and count: "Inserting variants... 12,450"
    - Use toLocaleString() for number formatting
  - Success section (v-if="isSuccess"): checkmark icon, "Import complete!" text
- v-card-actions with:
  - Cancel button (closes dialog when not importing, cancels import when importing)
  - Import button (:disabled until filePath and valid caseName, hidden during import/success)

**Script setup:**
- Refs: dialog, filePath, caseName, isImporting, isSuccess, errorMessage, progress
- IPC progress listener setup in onMounted with cleanup in onUnmounted (critical for memory leak prevention)
- show() method: opens dialog, resets state, calls selectFile immediately
- handleBrowse(): calls window.api.import.selectFile(), extracts default case name from path
- handleImport(): validates, calls window.api.import.start(), handles result/error
- handleCancel(): if isImporting calls window.api.import.cancel(), always closes dialog
- showSuccessAndClose(): sets isSuccess=true, setTimeout 1500ms to close and emit

**Case name extraction from path:**
```typescript
const extractCaseName = (path: string): string => {
  let name = path.split('/').pop() || path.split('\\').pop() || 'import'
  if (name.endsWith('.gz')) name = name.slice(0, -3)
  if (name.endsWith('.json')) name = name.slice(0, -5)
  return name
}
```

**Error handling:**
- Use isIpcError type guard from @/shared/types/errors
- Check error.code === ErrorCode.UNIQUE_CONSTRAINT for duplicate case name
- Display error.userMessage for other errors
- Show "Try again" state (reset to allow re-browse/re-import)

**Emit:**
- 'import-complete' event with { caseId, variantCount, caseName } for parent to handle

**Validation rules:**
```typescript
const caseNameRules = [
  (v: string) => !!v || 'Case name is required',
  (v: string) => v.length >= 3 || 'Minimum 3 characters',
  (v: string) => v.length <= 50 || 'Maximum 50 characters'
]
```
