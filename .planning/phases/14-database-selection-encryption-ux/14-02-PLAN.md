<objective>
Build the complete database selection and encryption UI: a database picker dropdown in the app bar, password dialogs for encrypted databases, a create database dialog with optional encryption, a change password dialog, and a Pinia store for database state. Wire everything into App.vue so switching databases clears the current view and reloads data.

Purpose: This is the user-facing half of Phase 14. Users currently have no way to choose which database the app uses. This plan gives them full control: pick existing databases, create new ones (optionally encrypted), switch between them, and manage encryption passwords -- all without restarting.

Output: DatabasePicker component in app bar, PasswordDialog, CreateDatabaseDialog, ChangePasswordDialog, databaseStore, and updated App.vue with switch lifecycle.
</objective>

    **1. Create Pinia database store (src/renderer/src/stores/databaseStore.ts):**
    - Use `defineStore('database', () => { ... })` (setup store syntax, consistent with any existing Pinia patterns).
    - State:
      - `currentPath: ref<string | null>(null)` -- full path to current database
      - `currentName: ref<string>('')` -- filename only
      - `isEncrypted: ref<boolean>(false)` -- whether current DB is encrypted
      - `isLoading: ref<boolean>(false)` -- true during open/switch/create operations
      - `recentDatabases: ref<RecentDatabase[]>([])` -- recent database list
    - Import `DatabaseInfo`, `RecentDatabase`, `DatabaseOpenResult` from shared types.
    - Actions:
      - `async fetchInfo(): Promise<void>` -- Call `window.api.database.info()`. Update currentPath, currentName, isEncrypted. Also call `fetchRecent()`.
      - `async fetchRecent(): Promise<void>` -- Call `window.api.database.recentList()`. Update recentDatabases.
      - `async openDatabase(path: string, password?: string): Promise<DatabaseOpenResult>` -- Set isLoading=true. Call `window.api.database.open(path, password)`. On success, update state from result.info. Call fetchRecent(). Set isLoading=false. Return result.
      - `async createDatabase(path: string, password?: string): Promise<DatabaseOpenResult>` -- Set isLoading=true. Call `window.api.database.create(path, password)`. On success, update state. Call fetchRecent(). Set isLoading=false. Return result.
      - `async selectAndOpenFile(): Promise<DatabaseOpenResult | null>` -- Call `window.api.database.selectFile()`. If null (cancelled), return null. Call `openDatabase(path)`. Return result.
      - `async selectSaveLocation(defaultName: string): Promise<string | null>` -- Call `window.api.database.selectSaveLocation(defaultName)`. Return path or null.
      - `async changePassword(newPassword: string): Promise<{ success: boolean; error?: string }>` -- Call `window.api.database.rekey(newPassword)`. Return result.

      - Also track `pendingOpenPath: ref<string | null>(null)` for the path that needs a password.

      - `handleOpen()`: Call `databaseStore.selectAndOpenFile()`. If result `needsPassword`, store path and open PasswordDialog. If error, emit `error`.
      - `handleCreate()`: Open CreateDatabaseDialog.
      - `handleChangePassword()`: Open ChangePasswordDialog.
      - `handlePasswordSubmit(password: string)`: Call `databaseStore.openDatabase(pendingOpenPath, password)`. If WRONG_PASSWORD error, pass error back to PasswordDialog. If success, close dialog, emit `database-switched`.
      - Emit events: `database-switched` (when any switch completes), `error` (when operation fails with user message).
    - Style: Follow warm palette theme. No scoped styles needed beyond standard Vuetify.
