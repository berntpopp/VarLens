<objective>
Refactor DatabaseService from a hardcoded singleton to a lifecycle-aware service, create a DatabaseManager that supports open/close/switch with rollback, add a RecentDatabasesService for persistent recent databases, and wire up IPC handlers so the renderer can control database lifecycle.

Purpose: This is the backend foundation for Phase 14. Without lifecycle management, the app is locked to a single database file forever. Every IPC handler currently calls `getDatabaseService()` which returns a singleton -- that pattern must be replaced with a centralized DatabaseManager that all handlers use.

Output: DatabaseManager service, RecentDatabasesService, database IPC handlers, refactored getDatabaseService, updated preload bridge with `database` namespace.
</objective>

  <action>
    **1. Add `clearStatementCache()` method to DatabaseService (src/main/database/DatabaseService.ts):**
    - Add a public `clearStatementCache(): void` method that calls `this.statementCache.clear()`.
    - Update the existing `close()` method to call `this.clearStatementCache()` before `this.db.close()`.
    - Add an optional `key` parameter to the constructor: `constructor(dbPath: string = ':memory:', key?: string)`.
    - If `key` is provided, execute `this.db.pragma(\`key='${key}'\`)` as the FIRST operation after `new Database(dbPath)`, BEFORE WAL mode, foreign keys, and schema initialization. This satisfies DBSC-02 (PRAGMA key first).
    - Add a public `isEncrypted(): boolean` method. Track whether a key was provided in a private boolean field `private encrypted: boolean`. Return this in `isEncrypted()`.
    - Add a public `getPath(): string` method that returns the dbPath stored in a private field.
    - Add a public `rekey(newPassword: string): void` method that executes `this.db.pragma(\`rekey='${newPassword}'\`)`. Note: This only works on already-encrypted databases (research confirmed PRAGMA rekey cannot encrypt plaintext).

    **2. Refactor database/index.ts to use DatabaseManager (src/main/database/index.ts):**
    - Remove the singleton `databaseService` variable and the `getDatabaseService()` function.
    - Remove the `closeDatabaseService()` function.
    - Instead, import and re-export `DatabaseManager` from `../services/DatabaseManager`.
    - Add a module-level `let databaseManager: DatabaseManager | null = null` variable.
    - Export `function initDatabaseManager(): DatabaseManager` that creates the DatabaseManager singleton (if not already created) and opens the default database at `join(app.getPath('userData'), 'varlens.db')`.
    - Export `function getDatabaseManager(): DatabaseManager` that returns the singleton (throws if not initialized).
    - Export `function getDatabaseService(): DatabaseService` as a convenience that calls `getDatabaseManager().getCurrent()` and throws if no database is open. This preserves backward compatibility with existing IPC handlers so they continue working without changes to their internal logic.
    - Export `function closeDatabaseManager(): void` that calls `databaseManager.close()` and sets it to null.
    - Keep existing type and error re-exports.

    **3. Add EncryptionError to database errors (src/main/database/errors.ts):**
    - Add a new `WrongPasswordError` class extending `DatabaseError` with message "Wrong password or database is not encrypted".
    - Add a new `EncryptionError` class extending `DatabaseError` for general encryption failures.

    **4. Create DatabaseManager service (src/main/services/DatabaseManager.ts):**
    - Create `src/main/services/` directory if it doesn't exist.
    - Class `DatabaseManager` with:
      - `private currentDb: DatabaseService | null = null`
      - `private currentPath: string | null = null`
      - `private recentDatabases: RecentDatabasesService`
    - Constructor takes `recentDatabases: RecentDatabasesService`.
    - Method `open(dbPath: string, key?: string): void`:
      - Close current DB if open (call `this.close()`).
      - Create new `DatabaseService(dbPath, key)`.
      - If key is provided, validate password by running `this.currentDb.database.prepare('SELECT count(*) FROM sqlite_master').get()`. Catch errors: if message includes 'file is encrypted or is not a database', throw `WrongPasswordError`. Otherwise rethrow.
      - Store `currentDb` and `currentPath`.
      - Add to recent databases list via `this.recentDatabases.addRecent(dbPath)`.
    - Method `openDetectEncryption(dbPath: string): { needsPassword: boolean }`:
      - Try opening without key. Run `SELECT count(*) FROM sqlite_master`.
      - If succeeds: database is plaintext. Return `{ needsPassword: false }`.
      - If fails with 'file is encrypted or is not a database': close the test connection, return `{ needsPassword: true }`.
      - If fails with other error: throw it.
    - Method `createDatabase(dbPath: string, key?: string): void`:
      - Close current if open.
      - Create new `DatabaseService(dbPath, key)` (constructor handles PRAGMA key + schema init).
      - Store as current, add to recents.
    - Method `switchDatabase(newPath: string, key?: string): void`:
      - Implement rollback pattern from research:
      - Save reference to `previousDb` and `previousPath`.
      - Try: open new DB at `newPath` with optional `key`. Validate with SELECT if key provided.
      - On success: close `previousDb` (clearStatementCache + close). Update current.
      - On failure: restore `previousDb` as current, rethrow error.
      - Add to recents on success.
    - Method `close(): void` -- close current DB safely (clearStatementCache + close), null out references.
    - Method `getCurrent(): DatabaseService` -- return currentDb, throw `DatabaseError('No database is currently open')` if null.
    - Method `getCurrentPath(): string | null` -- return currentPath.
    - Method `getCurrentInfo(): { path: string; name: string; encrypted: boolean } | null` -- return null if no DB, otherwise extract filename from path using `path.basename()`.
    - Method `rekey(newPassword: string): void` -- call `getCurrent().rekey(newPassword)`.

    **5. Create RecentDatabasesService (src/main/services/RecentDatabasesService.ts):**
    - NOTE: Do NOT use `electron-store` (ESM-only, complicates build). Instead, use the same simple JSON settings file approach already used in `src/main/ipc/handlers/import.ts` (readFileSync/writeFileSync to userData/settings.json).
    - Read/write to `join(app.getPath('userData'), 'varlens-settings.json')`.
    - Interface `RecentDatabase { path: string; name: string; lastOpened: number }`.
    - Interface `SettingsData { recentDatabases: RecentDatabase[] }`.
    - Class `RecentDatabasesService`:
      - `private maxRecent = 5`
      - `private settingsPath: string` (set in constructor)
      - `addRecent(dbPath: string): void` -- extract filename via `path.basename()`, remove existing entry for same path, prepend new entry, trim to maxRecent, write.
      - `getRecent(): RecentDatabase[]` -- read and return list.
      - `removeRecent(dbPath: string): void` -- filter out entry, write.
      - Private `load(): SettingsData` and `save(data: SettingsData): void` using try/catch with readFileSync/writeFileSync (same pattern as existing import handler settings).
