  2. Update `electron.vite.config.ts` to inject __APP_VERSION__ into the renderer process. Import package.json version and add a `define` block to the renderer config:
     ```typescript
     import pkg from './package.json'

       __APP_VERSION__: JSON.stringify(pkg.version)
     ```

  4. Create `src/renderer/src/composables/useVersionGating.ts`:
     - Declare `__APP_VERSION__` as a global string constant for TypeScript (use `declare const __APP_VERSION__: string`)
     - Define STORAGE_KEY as `'varlens_disclaimer_acknowledged_version'`
     - Export `useVersionGating()` function returning:
       - `currentVersion: string` (from __APP_VERSION__)
       - `needsAcknowledgment(): boolean` -- returns true if localStorage value !== currentVersion
       - `recordAcknowledgment(): void` -- writes currentVersion to localStorage
       - `clearAcknowledgment(): void` -- removes the localStorage key
     - Access localStorage ONLY inside function bodies (never at module level) to avoid Electron renderer timing issues
     - Keep it simple: string equality comparison, no semver parsing
     - Follow same export pattern as useDebounce.ts (named export function)

  1. Create `src/renderer/src/components/DisclaimerDialog.vue`:
     - Use Vue 3 Composition API with `<script setup lang="ts">`
     - Template structure:
       - `v-dialog` with `v-model="isOpen"`, `persistent` (blocks ESC and outside click), `max-width="600"`, `scrim` (dim overlay behind)
       - `v-card` with:
         - `v-card-title` displaying `config.title`
         - `v-card-text` with:
           - Introduction paragraph from `config.introduction`
           - `v-list` with `density="compact"` containing limitation items
           - Each `v-list-item` has:
             - `#prepend` template slot with `v-icon` using `limitation.icon`, `size="small"`, `color="primary"`
             - `v-list-item-title` with `limitation.title` (bold)
             - `v-list-item-subtitle` with `limitation.text` (wrapping text, use `style="white-space: normal"`)
           - Footer text paragraph from `config.footer` in italic/muted style
         - `v-card-actions` with `v-spacer` and single `v-btn` with `color="primary"`, `variant="flat"`, text from `config.acknowledgeButtonText`, click calls `handleAcknowledge`
     - Script:
       - Import disclaimerConfig from `'../config/disclaimerConfig.json'`
       - Import useVersionGating from `'../composables/useVersionGating'`
       - `isOpen = ref(false)`
       - Destructure `{ needsAcknowledgment, recordAcknowledgment }` from `useVersionGating()`
       - `handleAcknowledge`: call `recordAcknowledgment()`, set `isOpen.value = false`, emit `'acknowledged'`
       - `checkAndShow`: if `needsAcknowledgment()` returns true, set `isOpen.value = true`
       - `show`: unconditionally set `isOpen.value = true` (for re-opening from shortcut)
       - `defineExpose({ checkAndShow, show })` to allow App.vue to call these methods
       - `defineEmits<{ acknowledged: [] }>()` for the acknowledge event
     - Do NOT use `onMounted` to auto-check -- let App.vue control when to check (avoids Pitfall 4 from research)
     - Do NOT set `hide-overlay` or `no-click-animation` -- persistent + scrim is correct combination

  2. Update `src/renderer/src/App.vue`:
     - Add import for DisclaimerDialog component
     - Add component ref: `const disclaimerRef = ref<InstanceType<typeof DisclaimerDialog> | null>(null)`
     - Place `<DisclaimerDialog ref="disclaimerRef" @acknowledged="handleDisclaimerAcknowledged" />` in template (inside v-app, after LogViewer)
     - In existing `onMounted` hook, add disclaimer check AFTER the demo log seeding:
