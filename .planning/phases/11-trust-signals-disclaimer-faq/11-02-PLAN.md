  2. Create `src/renderer/src/composables/useKeyboardShortcuts.ts`:
     - Import `onKeyStroke` from `'@vueuse/core'`
     - Export function `useKeyboardShortcuts(callbacks: { onDisclaimer?: () => void; onFaq?: () => void; onLogViewer?: () => void })`
     - Register Ctrl+Shift+D for disclaimer: check `(e.ctrlKey || e.metaKey) && e.shiftKey && e.key === 'D'`, call `e.preventDefault()` then `callbacks.onDisclaimer?.()`
     - Register Ctrl+Shift+Q for FAQ: check `(e.ctrlKey || e.metaKey) && e.shiftKey && e.key === 'Q'`, call `e.preventDefault()` then `callbacks.onFaq?.()`
     - Register Ctrl+L for log viewer: check `(e.ctrlKey || e.metaKey) && e.key === 'l'`, call `e.preventDefault()` then `callbacks.onLogViewer?.()`
     - Return a cleanup function that calls all three stop functions from onKeyStroke
     - Use `(e.ctrlKey || e.metaKey)` to support both Windows/Linux (Ctrl) and macOS (Cmd)
     - Always `e.preventDefault()` to prevent browser defaults (Ctrl+D bookmarks, Ctrl+Q quits, Ctrl+L address bar)

     - Script:

       - `groupedFaq = computed(() => { ... })`: group `filteredFaq` items by category, returning an array of `{ category: string, items: FaqItem[] }` objects, maintaining original category order.
