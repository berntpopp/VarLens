Create src/main/services/api/HpoApiClient.ts:

Import zod schema from './schemas/hpo-response', ApiCache from './ApiCache'.

Class HpoApiClient:
- Constructor takes ApiCache instance
- Private baseUrl = 'https://clinicaltables.nlm.nih.gov/api/hpo/v3/search'
- No rate limiter needed - NLM API has no documented limits (but implement courtesy 5 req/sec)
- Private courtesy limiter using simple time tracking (not Bottleneck - overkill for HPO):
  - lastRequestTime: number = 0
  - minDelay: number = 200 (5 req/sec)

Methods:
- async search(query: string, maxResults = 20): Promise<HpoSearchResult>
  1. If query.length < 2, return { success: true, terms: [] } (min 2 chars per CONTEXT.md)
  2. Generate cache key: `hpo:search:${query.toLowerCase().trim()}:${maxResults}`
  3. Check cache first - HPO terms don't change often, cache for 30 days
  4. If cached, parse and return
  5. Apply courtesy delay: wait if needed since lastRequestTime
  6. Build URL with params: terms=query, count=maxResults, df=id,name (display fields)
  7. Fetch with timeout (10s - NLM can be slow)
  8. Validate with HpoAutocompleteResponseSchema.parse()
  9. Transform tuple format to HpoTerm array: response[3].map(([id, name]) => ({ id, name }))
  10. Cache transformed result
  11. Return { success: true, terms }
  12. Catch errors: return { success: false, error: message, offline: false }

- getCached(query: string, maxResults: number): HpoTerm[] | null
  - For offline access to previously searched terms
  - Parse and return, or null if not cached

- clearCache(): void
  - this.cache.clearByPrefix('hpo:')

Note: The NLM Clinical Tables API searches by name, ID, AND synonyms automatically - no special handling needed. Query "seizure" returns HP:0001250 Seizure and related terms including those with "seizure" in synonyms.

- IPC handlers:
  1. ipcMain.handle('vep:fetch', async (_event, chr, pos, ref, alt) => {
       - Check NetworkStatus.getStatus() first
       - If offline: try vepClient.getCached(), return with offline: true flag
       - If online: call vepClient.fetchVariantAnnotation()
       - Return VepFetchResult structure
     })
  2. ipcMain.handle('vep:cancel', async () => {
       - Call vepClient.cancelPendingRequest()
     })
  3. ipcMain.handle('vep:clearCache', async () => {
       - Call vepClient.clearCache()
       - Return { success: true }
     })
  4. ipcMain.handle('vep:getCacheStats', async () => {
       - Return cache.getCacheStats() filtered to VEP entries
     })
