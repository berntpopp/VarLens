<task type="auto">
  <name>Task 1: Add case metadata methods to DatabaseService</name>
  <files>src/main/database/DatabaseService.ts</files>
  <action>
Add case metadata CRUD methods to DatabaseService following the atomic upsert pattern from annotation methods.

**CaseMetadata methods:**
- `getCaseMetadata(caseId: number): CaseMetadata | null` - Fetch metadata for a case
- `upsertCaseMetadata(caseId: number, updates: CaseMetadataUpdates): CaseMetadata` - Atomic upsert with COALESCE pattern:
  ```sql
  INSERT INTO case_metadata (case_id, affected_status, notes, created_at, updated_at)
  VALUES (?, ?, ?, ?, ?)
  ON CONFLICT(case_id) DO UPDATE SET
    affected_status = COALESCE(excluded.affected_status, affected_status),
    notes = COALESCE(excluded.notes, notes),
    updated_at = excluded.updated_at
  RETURNING *
  ```

**CohortGroup methods:**
- `listCohortGroups(): CohortGroup[]` - List all cohort groups ordered by name
- `createCohortGroup(name: string, description?: string | null): CohortGroup` - Create new cohort, return created row
- `deleteCohortGroup(cohortId: number): void` - Delete cohort (CASCADE handles links)
- `getCohortGroupByName(name: string): CohortGroup | null` - For checking existence before creation

**Case-Cohort link methods:**
- `getCaseCohorts(caseId: number): CohortGroup[]` - Get all cohorts for a case via JOIN
- `assignCaseCohort(caseId: number, cohortId: number): void` - INSERT with ON CONFLICT DO NOTHING
- `removeCaseCohort(caseId: number, cohortId: number): void` - DELETE from junction table
- `setCaseCohorts(caseId: number, cohortIds: number[]): void` - Replace all cohort assignments atomically (delete existing, insert new)

**HPO term methods:**
- `getCaseHpoTerms(caseId: number): CaseHpoTerm[]` - Get all HPO terms for a case
- `assignCaseHpoTerm(caseId: number, hpoId: string, hpoLabel: string): CaseHpoTerm` - Upsert with label update:
  ```sql
  INSERT INTO case_hpo_terms (case_id, hpo_id, hpo_label, created_at)
  VALUES (?, ?, ?, ?)
  ON CONFLICT(case_id, hpo_id) DO UPDATE SET hpo_label = excluded.hpo_label
  RETURNING *
  ```
- `removeCaseHpoTerm(caseId: number, hpoId: string): void` - DELETE specific term

Import CaseMetadata, CohortGroup, CaseHpoTerm types from './types'.

All methods use this.stmt() for prepared statement caching.
