  <name>Task 1: Create TypeScript types for database entities</name>
  <files>src/main/database/types.ts</files>
  <action>
Create TypeScript interfaces for database entities:

**Case interface:**
- id: number (SQLite INTEGER PRIMARY KEY)
- name: string (unique case name)
- file_path: string (original import file path)
- file_size: number (file size in bytes)
- variant_count: number (count of variants for this case)
- created_at: number (Unix timestamp in milliseconds)

**Variant interface:**
- id: number (SQLite INTEGER PRIMARY KEY)
- case_id: number (foreign key to cases)
- chr: string (chromosome, e.g., "1", "X", "MT")
- pos: number (genomic position)
- ref: string (reference allele)
- alt: string (alternate allele)
- gene_symbol: string | null (gene symbol, nullable)
- consequence: string | null (variant consequence, nullable)
- gnomad_af: number | null (gnomAD allele frequency, nullable)
- cadd: number | null (CADD score, nullable)
- clinvar: string | null (ClinVar classification, nullable)

**VariantFilter interface:**
- case_id: number (required - always filter by case)
- gene_symbol?: string (partial match filter)
- consequence?: string (exact match filter)
- gnomad_af_max?: number (maximum allele frequency)
- cadd_min?: number (minimum CADD score)
- search_query?: string (FTS5 full-text search query)

**PaginationCursor interface:**
- id: number (last row id)
- sort_value: number | string (value of sort column for keyset)

**PaginatedResult<T> generic interface:**
- data: T[]
- next_cursor: PaginationCursor | null
- has_more: boolean
- total_count: number

Export all interfaces. Use snake_case for properties to match SQLite column naming.

Create typed error class hierarchy for database operations:

**DatabaseError (base class):**
- Extends Error
- message: string
- cause?: Error (optional wrapped error)
- Set name property to class name
- Use Object.setPrototypeOf(this, ClassName.prototype) for proper instanceof

**NotFoundError extends DatabaseError:**
- Constructor takes resource: string (e.g., "Case") and id: number | string
- Message format: "{resource} with id {id} not found"

**UniqueConstraintError extends DatabaseError:**
- Constructor takes field: string and value: string
- Message format: "{field} '{value}' already exists"

**TransactionError extends DatabaseError:**
- Constructor takes message: string and cause?: Error
- Used when transaction fails

Export all error classes. Follow TypeScript custom error best practices with Object.setPrototypeOf for proper prototype chain.

**schema.ts - Create SQL schema definitions:**

Export `createTables` constant (SQL string):
```sql
CREATE TABLE IF NOT EXISTS cases (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  name TEXT NOT NULL UNIQUE,
  file_path TEXT NOT NULL,
  file_size INTEGER NOT NULL,
  variant_count INTEGER NOT NULL DEFAULT 0,
  created_at INTEGER NOT NULL
);

CREATE TABLE IF NOT EXISTS variants (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  case_id INTEGER NOT NULL,
  chr TEXT NOT NULL,
  pos INTEGER NOT NULL,
  ref TEXT NOT NULL,
  alt TEXT NOT NULL,
  gene_symbol TEXT,
  consequence TEXT,
  gnomad_af REAL,
  cadd REAL,
  clinvar TEXT,
  FOREIGN KEY (case_id) REFERENCES cases(id) ON DELETE CASCADE
);
```

Export `createIndexes` constant (SQL string):
```sql
CREATE INDEX IF NOT EXISTS idx_variants_case_id ON variants(case_id);
CREATE INDEX IF NOT EXISTS idx_variants_gene ON variants(gene_symbol);
CREATE INDEX IF NOT EXISTS idx_variants_pos ON variants(chr, pos);
CREATE INDEX IF NOT EXISTS idx_variants_filters ON variants(gnomad_af, cadd);
```

Export `createFTSTable` constant (SQL string):
```sql
CREATE VIRTUAL TABLE IF NOT EXISTS variants_fts USING fts5(
  gene_symbol,
  consequence,
  content='variants',
  content_rowid='id',
  tokenize='unicode61 remove_diacritics 1',
  prefix='2 3'
);
```

Export `createFTSTriggers` constant (SQL string):
- AFTER INSERT trigger: inserts into variants_fts
- AFTER DELETE trigger: deletes from variants_fts (use INSERT with delete parameter for contentless FTS5)
- AFTER UPDATE trigger: updates variants_fts

Export `initializeSchema(db: Database)` function:
- Takes better-sqlite3 Database instance
- Executes createTables, createIndexes, createFTSTable, createFTSTriggers in order
- No return value (throws on error)
