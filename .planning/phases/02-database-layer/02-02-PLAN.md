<task type="auto">
  <name>Task 1: Create DatabaseService class with initialization and case CRUD</name>
  <files>src/main/database/DatabaseService.ts</files>
  <action>
Create DatabaseService class that manages SQLite connection and case operations:

**Constructor:**
- Takes optional dbPath: string (defaults to app.getPath('userData') + '/varlens.db' in production)
- Opens better-sqlite3 Database instance
- Sets pragma: journal_mode = WAL
- Sets pragma: foreign_keys = ON
- Calls initializeSchema(db) from schema.ts
- Initializes empty Map for prepared statement cache
- Wrap in try/catch, throw DatabaseError on failure

**Private methods:**

`private stmt(sql: string): Database.Statement`
- Check if statement exists in cache Map
- If not, prepare and cache it
- Return cached statement
- This provides prepared statement caching (DB-07)

`private transaction<T>(fn: () => T): T`
- Create transaction using db.transaction(fn)
- Execute and return result
- Wrap errors in TransactionError (DB-08)

**Case operations (DB-03):**

`createCase(name: string, filePath: string, fileSize: number): number`
- Insert into cases table with created_at = Date.now()
- Return lastInsertRowid as number
- Catch SQLITE_CONSTRAINT_UNIQUE error, throw UniqueConstraintError

`getCase(id: number): Case`
- Select * from cases where id = ?
- Throw NotFoundError if no result
- Return Case object

`getCaseByName(name: string): Case`
- Select * from cases where name = ?
- Throw NotFoundError if no result
- Return Case object

`getAllCases(): Case[]`
- Select * from cases order by created_at desc
- Return array of Case objects

`updateCaseVariantCount(id: number, count: number): void`
- Update cases set variant_count = ? where id = ?
- Throw NotFoundError if no rows affected

`deleteCase(id: number): void`
- Delete from cases where id = ?
- Throw NotFoundError if no rows affected
- Note: ON DELETE CASCADE handles variant deletion

**Utility:**

`close(): void`
- Close database connection

`get database(): Database.Database`
- Expose db instance for testing (read-only getter)

Import types from ./types.ts, errors from ./errors.ts, initializeSchema from ./schema.ts.
Handle the conditional app.getPath import gracefully for testing (allow dbPath override).
