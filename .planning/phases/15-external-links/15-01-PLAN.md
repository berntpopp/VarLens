  <name>Task 1: Create URL builder utility functions</name>
  <files>src/renderer/src/utils/externalLinks.ts</files>
  <action>
Create `src/renderer/src/utils/externalLinks.ts` with pure functions that construct external database URLs from variant data. This file has ZERO side effects -- no DOM, no IPC, no imports beyond standard TypeScript.

Export a `GenomeBuild` type:
```typescript
export type GenomeBuild = 'GRCh37' | 'GRCh38'
```

Implement eight URL builder functions, each returning `string | null` (null when required data is missing):

1. **buildGnomadUrl(chr, pos, ref, alt, build)** -- gnomAD variant page
   - Requires: chr, pos, ref, alt (all must be truthy/non-zero)
   - GRCh37 uses dataset `gnomad_r2_1`, GRCh38 uses `gnomad_r4`
   - URL format: `https://gnomad.broadinstitute.org/variant/${chr}-${pos}-${ref}-${alt}?dataset=${dataset}`
   - Apply `encodeURIComponent` to ref and alt (handles indels with special chars)
   - Do NOT encode chr or pos (they are simple strings/numbers)

2. **buildClinvarUrl(clinvarId)** -- ClinVar variation page by ID
   - Parameter: `clinvarId: string | null`
   - Requires: non-null, non-empty clinvarId
   - URL format: `https://www.ncbi.nlm.nih.gov/clinvar/variation/${clinvarId}/`
   - Apply `encodeURIComponent` to clinvarId
   - NOTE: This function is for future use when ClinVar ID is available in the schema (Phase 17+). It exists now for completeness and testability.

3. **buildClinvarSearchUrl(chr, pos, ref, alt)** -- ClinVar coordinate-based search
   - Requires: chr (truthy), pos (> 0), ref (truthy), alt (truthy)
   - URL format: `https://www.ncbi.nlm.nih.gov/clinvar/?term=${chr}:${pos}:${ref}:${alt}`
   - Apply `encodeURIComponent` to the entire search term string (`${chr}:${pos}:${ref}:${alt}`)
   - This is the primary ClinVar link used in Phase 15 since the Variant interface does NOT have a clinvar_id field yet

4. **buildOmimUrl(mimNumber)** -- OMIM entry page by MIM number
   - Parameter: `mimNumber: string | null`
   - Requires: non-null, non-empty mimNumber
   - URL format: `https://omim.org/entry/${mimNumber}`
   - Apply `encodeURIComponent` to mimNumber
   - NOTE: This function is for future use when MIM number is available in the schema (Phase 17). It exists now for completeness and testability.

5. **buildOmimGeneSearchUrl(geneSymbol)** -- OMIM gene search fallback
   - Parameter: `geneSymbol: string | null`
   - Requires: non-null, non-empty geneSymbol
   - URL format: `https://omim.org/search?search=${geneSymbol}`
   - Apply `encodeURIComponent` to geneSymbol
   - This is the primary OMIM link used in Phase 15 since the Variant interface has gene_symbol but NOT omim_mim_number

6. **buildUcscUrl(chr, pos, build)** -- UCSC Genome Browser region view
   - Requires: chr (truthy), pos (> 0)
   - GRCh37 uses db `hg19`, GRCh38 uses `hg38`
   - Window: pos - 25 to pos + 25 (narrow 50bp window centered on variant)
   - Clamp start to minimum 1 (no negative positions)
   - URL format: `https://genome.ucsc.edu/cgi-bin/hgTracks?db=${db}&position=${chr}:${start}-${end}`
   - Apply `encodeURIComponent` to the entire position string (`chr:start-end`)

7. **buildVarsomeUrl(chr, pos, ref, alt, build)** -- VarSome variant interpretation
   - Requires: chr, pos, ref, alt (all must be truthy/non-zero)
   - GRCh37 uses genome `hg19`, GRCh38 uses `hg38`
   - URL format: `https://varsome.com/variant/${genome}/${chr}-${pos}-${ref}-${alt}`
   - Apply `encodeURIComponent` to ref and alt

8. **buildFranklinUrl(chr, pos, ref, alt, build)** -- Franklin variant interpretation
   - Requires: chr, pos, ref, alt (all must be truthy/non-zero)
   - URL format: `https://franklin.genoox.com/clinical-db/variant/snp/chr${chrNum}-${pos}-${ref}-${alt}/GRCh37` or `/GRCh38`
   - Franklin uses `chr` prefix on chromosome and build name directly in path
   - Apply `encodeURIComponent` to ref and alt
   - NOTE: Franklin URL format has LOW confidence from research. Use the pattern above as best guess; if it changes, only this one function needs updating.

**Important design decisions:**
- Each function takes primitive parameters (not the full Variant object) for testability and reuse
- All functions are synchronous pure functions
- null return means "cannot construct link, show dash placeholder"
- Use strict checks: `if (!chr || !pos || !ref || !alt) return null` -- treat empty string, 0, null, undefined as missing
- For pos specifically, check `pos > 0` (genomic positions are 1-based)
