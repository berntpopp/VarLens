<objective>
Make external links fully configurable via a Pinia store and settings UI. Users can toggle links on/off, edit URL templates with variable placeholders ({chr}, {pos}, {ref}, {alt}, {gene}, {build}), add custom links, and remove custom links. A gear icon in the app bar opens the settings dialog. Link configurations persist in localStorage.

Purpose: Power users and researchers at different institutions use different genomic databases. Making links configurable lets each user tailor VarLens to their workflow without code changes.

Output: externalLinksStore.ts (Pinia store), ExternalLinksSettings.vue (settings dialog), updated App.vue (gear icon), updated VariantTable.vue (dynamic rendering from store), updated shell.ts (dynamic domain sync).
</objective>

**Types to define in the store file:**

```typescript
/** Where a link appears in the variant table */
export type LinkColumn = 'pos' | 'chr' | 'clinvar' | 'gene_symbol' | 'virtual'

/** Configuration for a single external link */
export interface ExternalLinkConfig {
  /** Unique identifier */
  id: string
  /** Display name (e.g., "gnomAD", "ClinVar") */
  name: string
  /** URL template with variable placeholders */
  urlTemplate: string
  /** Which column this link attaches to (virtual = own column at end) */
  column: LinkColumn
  /** Which variant fields are required for this link */
  requiredFields: string[]
  /** Whether this link is currently enabled */
  enabled: boolean
  /** Whether this is a built-in default link (cannot be deleted) */
  isBuiltIn: boolean
}
```

**Supported template variables:**

| Variable | Source | Example |

**Store state:**
- `links: ref<ExternalLinkConfig[]>` — all configured links
- `genomeBuild: ref<GenomeBuild>` — current genome build (default GRCh37)

**Store actions:**
- `updateLink(id: string, updates: Partial<ExternalLinkConfig>)` — update any field of a link
- `toggleLink(id: string)` — toggle enabled/disabled
- `addCustomLink(config: Omit<ExternalLinkConfig, 'id' | 'isBuiltIn'>)` — add a user link (generate UUID for id, isBuiltIn=false)
- `removeLink(id: string)` — remove link (only if not built-in)
- `resetToDefaults()` — restore all built-in links to original state, remove all custom links
- `setGenomeBuild(build: GenomeBuild)` — update genome build

**Store getters (computed):**
- `enabledLinks` — only enabled links
- `linksByColumn(column: LinkColumn)` — links for a specific column
- `virtualLinks` — links where column === 'virtual' and enabled
- `configuredDomains` — unique domains extracted from all enabled link URL templates (for allowlist sync)

const configuredDomains = computed(() => {
  const domains = new Set<string>()
  for (const link of enabledLinks.value) {

      const dummyUrl = link.urlTemplate
        .replace(/\{[^}]+\}/g, 'x')

})
