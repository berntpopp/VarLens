    Create `src/main/ipc/handlers/shell.ts`:
    - Import `ipcMain` from electron and `shell` from electron
    - Register `ipcMain.handle('shell:openExternal', ...)` handler
    - Parse the URL with `new URL(url)` in a try/catch
    - Reject non-HTTPS protocols: `if (parsedUrl.protocol !== 'https:')` return `{ success: false, error: 'Only HTTPS URLs allowed' }`
    - Whitelist domains: `['github.com', 'opensource.org']` -- check hostname matches exactly or is a subdomain via `.endsWith('.${domain}')`
    - If domain not allowed: return `{ success: false, error: 'Domain not allowed' }`
    - If valid: `await shell.openExternal(url)` then return `{ success: true }`
    - On catch: return `{ success: false, error: 'Invalid URL' }`
    - Add JSDoc comment with channel name `shell:openExternal`
    - Follow the same self-registering pattern as existing handlers (import side-effects)

    Update `src/main/ipc/handlers/system.ts`:
    - Change `system:version` handler to return `{ app: app.getVersion(), electron: process.versions.electron }` instead of just `app.getVersion()`
    - This is a BREAKING CHANGE to the existing `system:version` return type -- consumers will need to read `.app` instead of using the string directly. Currently no renderer code calls `system:version` (Phase 12 is the first consumer), so this is safe.

    Update `src/main/ipc/index.ts`:
    - Add `import('./handlers/shell')` alongside existing handler imports in `registerIpcHandlers()`
