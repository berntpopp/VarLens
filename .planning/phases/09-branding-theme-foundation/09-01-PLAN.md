2. **Import custom.css in main.ts** -- add `import './assets/styles/custom.css'` after the vuetify import.

3. **Load Roboto Mono font in index.html** -- add a Google Fonts link for Roboto Mono (weights 400, 500) in the `<head>`.

IMPORTANT: The existing CSP meta tag restricts style-src to 'self' 'unsafe-inline'. Loading from Google Fonts CDN requires adding `https://fonts.googleapis.com` to style-src and `https://fonts.gstatic.com` to font-src. Update the CSP accordingly:
```
content="default-src 'self'; script-src 'self'; style-src 'self' 'unsafe-inline' https://fonts.googleapis.com; font-src 'self' https://fonts.gstatic.com"
```

NOTE: If the offline-first constraint is a concern (CSP / no network), consider bundling Roboto Mono locally instead. But for development speed, CDN is fine -- production can self-host later.
