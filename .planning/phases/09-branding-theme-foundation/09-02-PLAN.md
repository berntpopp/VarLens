**App.vue changes:**

Restructure the template to add a v-app-bar and convert AppSidebar into a v-navigation-drawer:

1. Add `v-app-bar` with these properties:
   - `color="primary"` (uses warm palette primary from theme)
   - `density="compact"` (target ~48px height)
   - `flat` (no elevation shadow -- clean look)
   - Contents:
     - `v-app-bar-nav-icon` with `@click="sidebarOpen = !sidebarOpen"` and `aria-label="Toggle navigation sidebar"`
     - `v-icon icon="custom:varlens-dna"` with `class="ml-2"` and `size="small"`
     - `v-app-bar-title` with `class="ml-2 text-subtitle-1 font-weight-bold"` containing text "VarLens"
   - The app bar text should be white (on-primary) -- Vuetify handles this automatically via theme

2. Convert the sidebar to a `v-navigation-drawer`:
   - Add `v-navigation-drawer` wrapping the existing sidebar content
   - Props: `v-model="sidebarOpen"`, `width="280"`
   - Do NOT use `permanent` -- let the toggle button control visibility
   - Default `sidebarOpen` to `true` (sidebar visible on launch)

3. Refactor AppSidebar.vue:
   - Remove the `v-navigation-drawer` wrapper from AppSidebar -- it moves to App.vue
   - Remove the toolbar with mdi-dna icon and "Cases" text (this is replaced by the app bar)
   - Remove the rail toggle logic (the app bar toggle replaces it with show/hide)
   - Keep the `<slot />` content pass-through and the import-click emit
   - Add a compact toolbar or header section inside AppSidebar with just "Cases" label and the import (+) button
   - Use `color="primary"` for the internal header to maintain visual connection to app bar

4. Add `sidebarOpen` ref to App.vue script:
   ```typescript
   const sidebarOpen = ref(true)
   ```

**Key design decisions:**
- App bar is the SINGLE source of VarLens branding (name + icon)
- Sidebar is a content panel controlled by the app bar toggle, not an independent branded element
- The sidebar header shows "Cases" label + import button (functional, not branding)
- Compact app bar (~48px) maximizes vertical space for data-dense views
