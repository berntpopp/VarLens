    Create a composable that manages panel resize logic with localStorage persistence.

    Export `usePanelResize()` function that returns:
    - `panelWidth: Ref<number>` - current width (default 400px)
    - `isResizing: Ref<boolean>` - resize state
    - `startResize: (e: MouseEvent) => void` - mousedown handler
    - `minWidth: number` - 300px constant
    - `maxWidth: number` - 800px constant

    Implementation details:
    - Load initial width from localStorage key `varlens_panel_width` on init
    - On mousedown, capture startX and startWidth, add mousemove/mouseup listeners to document
    - On mousemove, calculate delta (startX - e.clientX for right drawer) and clamp to min/max
    - On mouseup, persist to localStorage and remove listeners
    - Use cleanup in onUnmounted to remove any lingering listeners

    Follow existing composable patterns in the codebase (see useAnnotations.ts for reference).

<task type="auto">
  <name>Task 2: Create VariantDetailsPanel component</name>
  <files>src/renderer/src/components/VariantDetailsPanel.vue</files>
  <action>
    Create the main panel component using Vuetify v-navigation-drawer.

    Props:
    - `open: boolean` (v-model) - controls drawer visibility
    - `variant: Variant | CohortVariant | null` - selected variant data
    - `caseId: number | null` - for per-case annotations (null in cohort mode)
    - `mode: 'case' | 'cohort'` - determines which annotation methods to use

    Template structure:
    ```vue
    <v-navigation-drawer
      :model-value="open"
      location="right"
      temporary
      :persistent="true"
      :width="panelWidth"
      @update:model-value="emit('update:open', $event)"
    >
      <!-- Resize handle (left edge) -->
      <div class="resize-handle" @mousedown="startResize" />

      <v-card flat class="h-100 d-flex flex-column">
        <!-- Header with title and close button -->
        <v-toolbar color="transparent" density="compact" flat>
          <v-toolbar-title class="text-subtitle-1">
            Variant Details
          </v-toolbar-title>
          <v-btn icon size="small" @click="emit('update:open', false)">
            <v-icon>mdi-close</v-icon>
          </v-btn>
        </v-toolbar>

        <v-divider />

        <!-- Scrollable content area (placeholder for now) -->
        <div class="flex-grow-1 overflow-y-auto pa-3">
          <div v-if="variant" class="text-body-2">
            <strong>{{ variant.gene_symbol ?? 'Unknown' }}</strong>
            <div>{{ variant.chr }}:{{ variant.pos }}</div>
            <div>{{ variant.ref }} > {{ variant.alt }}</div>
          </div>
          <div v-else class="text-grey text-center">
            No variant selected
          </div>
        </div>
      </v-card>
    </v-navigation-drawer>
    ```

    Script setup:
    - Use usePanelResize composable for width and resize handlers
    - Add Escape key listener (keydown event on window)
    - Clean up Escape listener in onUnmounted
    - Emit 'update:open' with false when Escape pressed and panel is open

    Styles (scoped):
    ```css
    .resize-handle {
      position: absolute;
      left: 0;
      top: 0;
      bottom: 0;
      width: 6px;
      cursor: ew-resize;
      background: transparent;
      z-index: 10;
    }
    .resize-handle:hover {
      background: rgba(var(--v-theme-primary), 0.2);
    }
    ```

    Import Variant type from shared types and CohortVariant from cohort types.
  </action>
